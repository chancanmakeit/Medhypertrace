# 表现型 vs 归因:二元本体的正确定义(方法学备忘)

本文件记录一个核心方法学决定,供论文 Methods 与 rebuttal 使用。它回应"能否把 MAST-14
硬性二分为模型固有 vs 架构协作"这一质疑。

## 质疑(有效,必须回应)

一个自然的反对意见:MAST 标签描述的是**故障的表现形式/发生位置**(phenotype),不是**根因**。
因此:

1. **同一 MAST 标签可来自不同根因**。FM-3.2(无验证)可能是:纯架构缺陷(没有 verifier)/
   模型执行缺陷(有 verifier 规范但没执行)/ 规范不完整(没规定要验证)。
2. **同一模型能力问题可表现为不同 MAST 标签**。长上下文能力不足 → FM-1.4 / FM-2.3 /
   FM-2.5 / FM-3.2。
3. **很多故障是模型能力与架构设计复合的**,强行二分会丢信息。

结论(该反对意见的):不应把"模型固有 vs 架构"当作 MAST 的两个互斥大类;表现型与根因
应是两个**独立字段**。

## 我们的回应:采纳其"独立字段",但用"规范违反"而非"根因"作判据

**采纳的部分**:表现型(MAST 标签)与归因(A/B)确实是**两条独立的轴**,作为独立字段标注。
A/B **不从** MAST 标签机械派生。这一点该反对意见完全正确,已写入标注协议 §3.5。

**关键区别**:该反对意见默认"归因轴 = 根因(是模型的锅还是架构的锅)"。而**根因是认识论上
不确定的**(常常无法判定、需要概率),这正是它反对二分的理由。**我们不用根因作判据。**

我们的 A/B 判据是**操作性**的,基于 **V(τ):是否存在一条明确的、预定义的规范被违反**:

- **A(架构-协作类)**:存在一条该 agent 本应遵守的明确规范,且它被违反了。V(τ) ≠ ∅。
- **B(模型固有类)**:没有任何预定义规范被违反(agent 忠实履职、走完流程),但输出内容仍错。
  V(τ) = ∅ —— 失败"逃逸"于规范归因。

**为什么这个判据稳健**(回应上面三条):

1. **同一 FM 标签不同根因** → 我们的 A/B 是**逐轨迹**判定,不是逐标签映射。FM-3.2 的三场景在
   我们的判据下自然得到不同 A/B(有规范且违反=A;无规范=B/不确定),**不矛盾**。
2. **同一能力问题不同 FM 标签** → 无所谓,因为我们不靠 FM 标签推 A/B。表现型可以多样,归因
   判据只问"有没有违反规范"。
3. **复合故障** → V(τ) 不问"多少比例是模型的锅",只问"有没有一条规范被违反"。这是一个可判定的
   二元问题,不需要拆解复合根因。

**一句话**:反对意见打在"根因二分"上;我们用"规范违反(V(τ))"二分,**不问根因**,从而绕开了
根因的不确定性。表现型与归因独立(采纳反对意见的核心洞察),但归因判据是操作性的规范违反,
而非认识论上的根因。

## 我们**不**采纳的部分:连续的根因贡献度

该反对意见进一步建议用连续/多标签的根因贡献度(model_contribution=high,
architecture_contribution=medium)。我们**不采纳**,原因:

- 我们的核心发现是"存在一类失败**逃逸**于归因本体"——这需要一个**清晰的二元判定**
  (V(τ) = ∅ 与否),而不是一个连续分。连续贡献度会把"逃逸"这个二元发现**软化**成程度问题,
  削弱论文的核心 claim。
- 连续根因贡献度对**诊断/修复**有价值,但那是另一篇工程论文的目标,不是本工作的科学发现。

因此:归因保持二元(A/B/不确定),不做连续贡献度。"不确定"这一档本身承载信息
(尤其若 B 类的归因分歧更大 → "模型固有失败更难归责"是一个发现)。

## 对训练/数据的直接后果(重要)

因为 A/B **不能**从 MAST 标签派生,而只能来自"这条轨迹是否违反了明确规范"的判断:

- **合成数据(AEGIS,按 MAST-14 注入)只有表现型标签,没有 A/B 归因标签。** 不能用合成数据
  自动生成 A/B 监督。
- **A/B 监督只能来自真实标注**(专家逐轨迹判 V(τ))。因此 A/B 头的训练数据 = 真实标注量,
  这是稀缺资源。
- 推论:**方法不是瓶颈,真实标注(尤其 A/B 与逃逸率)才是。** 精力应投在标注,而非方法复杂度。

## 对方法(双头)的后果

- **表现型头**:MAST-14 细粒度分类。合成数据可训。Error-Micro-F1 主指标。
- **归因头(A/B)**:轨迹级,监督来自真实标注的 V(τ) 字段。合成数据**不能**训。
- 两头共享超图骨干,但监督来源不同、不可混淆。

这也解释了为什么早先"A/B 头可从 MAST 标签确定性派生、现在就能训"的说法是**错误**的:
它把逐轨迹的规范违反判定错当成了逐标签映射,与本判据自相矛盾。已更正。
