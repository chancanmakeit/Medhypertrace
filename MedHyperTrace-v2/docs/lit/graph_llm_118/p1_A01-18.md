### #1 OFA（ICLR 2024，图基础模型）
- 一句话：用"文本属性图（TAG）+ 统一任务表示 + 提示子图"训练单一模型，同时做跨域的节点/边/图分类，并支持 few-shot / zero-shot。
- 核心机制：
  - 所有节点/边特征写成带固定格式的文本（`Feature node.` / `Feature edge.` 开头，"特征类型：内容"用分号连接），用同一个 LLM 编码到同一空间；实验对比了 sentence transformer、e5-large-v2、Llama2-7b/13b。
  - 任务统一：NOI（Nodes-of-Interest）。节点任务取 NOI={v}，边任务取两端点，图任务取全部节点。再挂一个携带任务描述文本的 NOI prompt 节点，替代各任务不同的 readout，并起 labeling trick 的作用。
  - GPP 提示图：每个候选类别一个"类节点"（带类别文本），与 prompt 节点相连。所有任务都化为类节点上的二分类，损失是二元交叉熵。
  - Zero-shot 靠类节点的文本语义：未见类直接挂新类节点即可。Few-shot 把每个 support 样本的 prompt 节点以新关系类型连到类节点。
  - 骨干是带边特征的 R-GCN 扩展，外加 layer attention。
- 关键数字：zero-shot 为 ogbn-arxiv 5-way 46.19%、Cora 2-way 56.92%、FB15K237 20-way 70.20%。去掉类节点（改为 NOI 平均池化加任务文本拼接）后，联合训练时 HIV 从 75.92 掉到 71.60。
- 【对 MAS 故障归因的可借鉴点】相关度：**高**
  - 任务统一模板：把"哪个 agent / 哪一步出错"写成 NOI = 候选 (agent, step) 节点集。归因问题是一个"在 NOI 集合上选类/选节点"的问题。
  - 类节点 + 文本描述可以让"错误类型 / 责任角色"这类标签空间跨框架共享，不依赖框架特有的角色 ID。
  - NOI prompt 节点连接一组节点，等价于超边的星形展开（推断）。因此"一轮投票 / 共享上下文"可以用一个携带任务文本的超边节点实现，不必改 GNN 骨干。
  - 负结果警示：联合训练时去掉任务/类节点会混淆任务。
  - 局限：文档指出 OFA 不支持回归，且只用了监督训练。

### #2 PRODIGY（NeurIPS Spotlight 2023，图基础模型）
- 一句话：第一个在图上实现 in-context learning 的预训练框架，用 prompt graph 把示例、查询和标签连起来，在新图上不更新参数就做分类。
- 核心机制：
  - 两阶段：data graph 编码器 M_D（GCN/GAT）加 task graph 编码器 M_T（注意力 GNN）。task graph 里有数据节点和标签节点，标签节点是信息瓶颈。
  - 预测用查询表示与标签表示的余弦相似度。
  - 预训练目标：自监督的 neighbor matching（判断节点属于哪个采样节点的 l-hop 邻域），加有监督 multi-task。另有 DropNode / MaskNode 增强，以及对被 mask 特征的重构损失。
  - 节点特征用预训练语言模型初始化。
- 关键数字：arXiv 节点分类上比 Contrastive 基线平均 +28.6%；纯自监督的 PG-NM 在 arXiv 3-way 达 69.07%，超过 TENT 的 65.13%。消融：去掉属性预测平均降 7%，去掉增强降 3%。
- 【对 MAS 故障归因的可借鉴点】相关度：**中**
  - 少量人工标注的轨迹可以当 prompt 示例（support），带标签边（T/F）连到"责任类"节点做 in-context 归因，不用针对新框架训练。
  - neighbor matching 是不依赖标签的自监督预训练，可用于大量无标注的真实 MAS 轨迹。
  - 注意：PRODIGY 只做分类，且文档给的评测只覆盖引文网络和 KG，没有轨迹/因果类任务。

### #3 ULTRA（ICLR 2024，图基础模型）
- 一句话：为知识图谱设计的基础模型。把关系类型之间的交互建成"关系图"，用查询条件化的 GNN 得到对任意新关系词表都适用的表示，实现全归纳的零样本链路预测。
- 核心机制：
  - 把图 lift 成关系图：节点是关系类型，边是四种基本交互（t2h / h2h / h2t / t2t）。
  - 用 labeling trick（查询关系节点初始化为全 1）加 NBFNet 式 GNN_r，得到以查询为条件的关系表示；再由 GNN_e 在实体层做链路预测。
  - 不学习任何图专属的实体/关系嵌入矩阵，总参数仅 177k。训练用二元交叉熵加负采样。
- 关键数字：零样本在 43 个有 SOTA 的图上平均 MRR 0.395，对监督 SOTA 的 0.344；微调 1000–2000 步后平均 0.422。预训练图超过 3 个后零样本性能饱和。去掉条件化相对 MRR 最多降 48%。
- 【对 MAS 故障归因的可借鉴点】相关度：**中**
  - 角色/消息类型词表因框架而异。可借"关系图"思路，只保留"谁→谁、谁回应谁"的交互模式作为不依赖角色名的结构表示，实现结构侧的词表无关（推断）。
  - 用"查询条件化 + labeling trick"让同一条轨迹在不同候选步骤查询下得到不同表示。
  - 局限：ULTRA 无文本、无 LLM。MAS 失败的核心是语义（内容对错），仅靠关系结构不够；文档中 SCGFM 的消融有类似现象（见 #13）。

### #4 GFT（NeurIPS 2024，图基础模型）
- 一句话：把计算树（消息传递展开树）当作图的可迁移"词汇"，用向量量化学习离散树词汇，并把节点/边/图任务统一成"计算树分类"。
- 核心机制：
  - 预训练：GNN 编码计算树，VQ 量化成 K 个 token。三个重构目标（根节点特征、树整体语义、树内拓扑）加正交正则。
  - 微调：任务统一靠虚拟节点（链路/图级任务添加虚拟节点连接所有相关节点）。树词汇冻结，只更新编码器和线性头，用原型分类器加线性分类器双头预测。
  - 实验使用文本属性图，文本编码器负责对齐特征。
- 关键数字：预训练加微调平均 79.92%，对最强基线 GAT 的 75.44 高 6% 以上；词汇大小 128/256/512 性能几乎无差别（约 79.9）。
- 【对 MAS 故障归因的可借鉴点】相关度：**中**
  - 冻结词汇只调编码器/头，可作为"轻量 adapter"的备选范式，用来缓解负迁移。
  - 用虚拟节点做任务统一，与 OFA 的 NOI prompt 节点同类。
  - 局限：文档指出只针对消息传递 GNN（受 1-WL 上限限制），且未覆盖 LLM 与零样本。

### #5 GIT（ICML 2025，图基础模型）
- 一句话：以"任务树"（任务相关节点的计算树加一个连接它们的虚拟任务节点）作统一学习实例，做重构式预训练，并可用 instruction tuning 特化。
- 核心机制：
  - 任务相关节点：节点任务是目标节点，边任务是两个端点，图任务是全部节点；用 MEAN 聚合各计算树嵌入。
  - GIT-G：两个损坏视图（随机边掩码加属性掩码）的 BYOL 式双向预测重构，加 KL 正则；骨干 GraphSAGE，节点特征用 Sentence-BERT 对齐。
  - GIT-S：在目标域任务树上监督后训练，目标是 LLM 编码的标签描述嵌入。
  - 零样本：用 LLM 生成的类别描述嵌入替代原型。
  - 理论：稳定性 / 可迁移性 / 泛化界三个定理，其中泛化界强调增大预训练数据多样性。
- 关键数字：GIT-G 的 held-out 平均为微调 75.37、3-shot 57.82、0-shot 27.50；GIT-S 的 0-shot 为 36.32、3-shot 为 60.15。任务树版本比子图版本 held-out 平均高（73.81 vs 70.88）且训练更快。
- 【对 MAS 故障归因的可借鉴点】相关度：**中**
  - 任务树 = "任务相关节点集合 + 虚拟节点"，天然对应"多方讨论/投票/共享上下文"这类多节点参与的事件（推断）。
  - 两阶段范式：通用预训练加"领域特化后训练"。可对应"通用轨迹预训练，再按医学 MAS 做特化"。
  - 警示：通用 0-shot 的绝对数很低（27.50），特化后才明显提升；领域专家（如分子上的 GIMLET）仍然更强。

### #6 GOFA（ICLR 2025，图基础模型）
- 一句话：把随机初始化的 GNN 层交错插入冻结的 LLM，用图级 next-word 预测等任务预训练，所有图任务统一成"在指定节点上补全图"的生成。
- 核心机制：
  - 图语言编码器：节点/边文本加 K 个 memory token 输入冻结 LLM（压缩器基于 ICAE）；token 级 GNN（改进的 TransConv）在 memory token 上做消息传递，与 LLM 层交替堆叠。
  - 门控：初始值为 0 的 tanh 门控，使初始模型等价于预训练 LLM。
  - 解码器：NOG 的 memory token 放在目标文本前，做 teacher-forcing 的标准 next-token 损失。
  - 任务统一：沿用 OFA，把所有任务转为以目标节点为根的 k-hop 子图，加携带用户查询的 prompt 节点，所以消息传递依赖 prompt。
  - 训练只更新 GNN 层，LLM 冻结。预训练任务包括句子补全、结构理解（最短路/公共邻居）、问答、信息检索，之后做小量指令微调。
- 关键数字：同等信息下，与"把图展平为文本输入 LLM"相比，GOFA 在 ExplaGraphs / Cora-Link / FB15K237 上准确率高 7%–69%，单样本推理时间少 14%–68%；WikiCS 上展平的 LLM 因长序列 OOM。最短路距离 RMSE 1.254→0.634。
- 【对 MAS 故障归因的可借鉴点】相关度：**高**
  - 最接近"graph + LLM、不重训 LLM"的架构。冻结 LLM 加可训练 GNN 层，可作为 adapter 的主方案；零初始化门控可以保证起点不劣于纯文本 LLM。
  - 复杂度：自注意力限制在节点内部，复杂度 O(Vk²)，对超长轨迹有利。
  - prompt 节点条件化的消息传递：同一图在不同查询下得到不同信息流。
  - 能生成文本，所以可以输出"为什么这一步是错因"的解释（推断）。
  - 警示：作者自述零样本评估仍集中在任务格式相似的数据集，不是全新任务格式。

### #7 UniGraph（原文标注 KDD，出处经复核订正（文档未给出订正后的会议）；2025，图基础模型）
- 一句话：用文本统一所有域的 TAG 特征，用 LM+GNN 级联骨干做掩码图建模预训练，再用 LLM 图指令微调实现零样本。
- 核心机制：
  - 任务模板：锚节点加上下文子图，节点任务用 top-k PPR 采样上下文。
  - 骨干：DeBERTa-base 加 3 层 GAT，取 [CLS] 嵌入。
  - Graph Siamese Masked Autoencoder：token 级掩码，用"邻居传播后的 [CLS]"加被掩码 token 的 LM 隐表示去重建被掩码文本（迫使模型用邻居文本恢复自己的文本）；再加 EMA 目标网络的潜空间正则，防坍缩。
  - 零样本（UniGraph-IT）：图嵌入线性投影到 Llama-7B 词嵌入空间，与指令拼接，LoRA 微调，生成式输出标签；指令微调数据的标签类别与下游无重叠。
  - 分子图等无文本图用模板转写成文本。
- 关键数字：线性探测上 Cora 81.43%、Arxiv 72.91%；零样本 Cora 7-way 69.53%（对 ZeroG 的 64.21%）。UniGraph-single 在 Cora 上 84.23%，高于跨域版的 81.43%；加入同域数据后 WN18RR 从 85.45% 升到 91.01%。
- 【对 MAS 故障归因的可借鉴点】相关度：**高**
  - 图 token → LLM 的投影：最直接的"图大模型"接口范式（图嵌入线性投影到 LLM 词嵌入空间，LoRA 微调，生成式输出标签）。
  - 掩码重建：遮住某一步的消息文本，用邻居步骤/其他 agent 的文本去恢复。这是可以用大量无标注真实轨迹做的自监督任务（推断），缓解"标注少、合成数据有模板伪迹"。
  - 警示：文档明确指出同域/单数据集训练比纯跨域更强，意味着"跨 MAS 框架零样本"可能是最难的一档。

### #8 ZeroG（KDD 2024，图基础模型）
- 一句话：用 LM 把节点文本和类别描述编码到同一空间，把节点分类改成"节点-类别文本相似度"，加 prompt 节点子图采样与 LoRA，实现跨数据集零样本。
- 核心机制：
  - 统一表示：同一个 LM（SentenceBert，768 维）对节点文本和类别描述编码。
  - 受限子图抽取：仅保留类别数不少于全数据集类别数一半的子图。
  - 数据集 prompt 节点：由数据集的描述文本初始化，全连接接入子图所有节点。
  - 邻域聚合：用对称归一化邻接矩阵迭代 λ 步。
  - 训练：只训练 LoRA（作用于 W_q、W_v，rank=4，α=16），用对比式交叉熵；推理时零微调，argmax 相似度。
- 关键数字：可训练参数仅 0.07M（OFA 为 20.7M，全参数微调 66.4M）。去掉 LoRA（全参数更新）后 Cora 降 51.36%、Citeseer 降 40.96%；去掉邻域聚合 Cora 降 25.43%、Pubmed 降 30.81%；跨域时 Citeseer / Pubmed 比同域分别降 11.77% / 8.90%。
- 【对 MAS 故障归因的可借鉴点】相关度：**高**
  - 轻量 adapter 的具体配方：LoRA 加零微调推理；证据显示全参数微调会严重过拟合，直接支持"只做轻量 adapter"。
  - 零节点打分方式：节点（步骤）文本嵌入与"错误类型/责任描述"文本嵌入做相似度，标签空间跨框架一致。
  - 数据集 prompt 节点可以改造成"MAS 框架描述节点"，用文字告诉模型当前框架的拓扑/角色（推断）。
  - 警示：子图/邻域聚合的归一化对不同子图规模至关重要（去掉后 Pubmed 降 38.77%），而 MAS 轨迹的规模差异大。

### #9 Position: Graph Foundation Models Are Already Here（ICML Spotlight，立场论文，2024，图基础模型）
- 一句话：提出"图词汇"视角，回顾图迁移性原理，讨论 GFM 的缩放定律、利用 LLM 的路线和开放问题。
- 核心机制：
  - 把 GFM 分为任务特定型（如 ULTRA）、领域特定型、原始型（如 OFA、PRODIGY、LLaGA）。
  - 成功词汇的两条原则：不能"压缩"（非同构的节点对不能映射到同一表示，否则负迁移）；要足够"包容"（新类型能映射到已有词汇）。
  - 链路预测需要 labeling trick，普通 GNN 因表达力不足会负迁移。
  - 利用 LLM 的四条路线中，作为预测器那条指出：简单把图结构 flatten 进 prompt 没有提升，与训练好的 GNN 差距大，需要结构编码器把结构嵌入映射成 prompt token。
- 关键数字：CiteSeer 有超过 15% 的错误标注；ogbn-arxiv 与 arxiv-year 图结构完全相同、仅标签不同，却呈现相互冲突的同配/异配性质。
- 【对 MAS 故障归因的可借鉴点】相关度：**中**
  - 为"要用 GNN/结构编码器而不是纯文本 flatten"提供动机，但注意这是立场文章，文档摘要中没有给出具体实验数字。
  - 负结果警示：数据若不服从迁移原理则 scaling 不会发生；跨域跨任务联合训练的正/负迁移之争尚未解决；合成图是缓解数据不足的建议路径之一。
  - 注意：文档还写到 Perozzi et al. (2024) 表明配上 LLM 后等变性不再必要，且当前图问答多为抽象图，缺少真实世界节点语义。

### #10 GraphPFN（ICML 2026，图基础模型）
- 一句话：用精心设计的合成属性图先验预训练图版 PFN（给表格基础模型 LimiX 加图适配器），做节点级任务的 in-context learning，微调后接近或达到 SOTA。
- 核心机制：
  - 合成先验：结构用多级 degree-corrected SBM 加优先连接（core-periphery）；节点属性/标签用混合 MLP/GNN 神经元的结构因果模型（SCM），可加 LapPE；所有超参从分布中采样。
  - 模型：在每个 LimiX 块末尾插入邻接掩码的稀疏多头注意力"图适配器"；只训练适配器，LimiX 冻结。
  - 损失：PFN 监督损失加 MGM（掩码 10% 边的边存在性判别）损失，系数 0.1。
  - 训练规模：400 万个合成数据集、50 万步、8×A100、约 6 天。
- 关键数字：微调后在 10 个可微调数据集中的 7 个上最优；随机初始化适配器再微调会显著退化（hm-prices 79.15→70.15，artnet-views 64.15→54.02）。失败案例：hm-prices（预训练只见过至多 194,425 条边的图，而它有 10,730,995 条边）、city-roads-M（路网拓扑与先验不符）。
- 【对 MAS 故障归因的可借鉴点】相关度：**高（作为"合成数据能否训出可迁移模型"的最直接参照）**
  - 合成先验预训练加冻结骨干加图适配器，在小标注、多合成数据的情况下训出可迁移模型，与用户"故障注入合成数据"的处境最接近。MAS 的"先验"可以设计成随机采样的拓扑、角色数、轮数、投票规则，以及带因果结构的错误传播过程（推断）。
  - 要点：对先验超参采样做多样化，覆盖不同框架的拓扑。
  - 失败归因明确：真实数据超出先验分布时失败。这直接对应"合成数据的模板伪迹 / 先验覆盖不足"的风险。
  - 局限：针对表格节点任务，无文本；需全图一次性处理，大图微调 OOM；原生分类 ≤10 类。

### #11 BrainGFM（ICLR 2026，图基础模型）
- 一句话：fMRI 脑网络图基础模型，用 GCL+GMAE 在多图谱语料上预训练，图提示加元学习做 few-shot，语言提示做 zero-shot。
- 核心机制：
  - Graph Transformer 骨干，每个 ROI 一个 token，用 RWSE 位置编码；输入前插入由图谱名称文本经 BioClinicalBERT 编码的 [A/P] token。
  - 图提示：结构与脑图一致的可学习节点向量加全可学习邻接矩阵，在多任务元学习下优化，主干冻结。
  - 语言提示：疾病描述与图谱名称经 BioClinicalBERT 编码、投影为 [T/D]、[A/P] token，与 ROI token 拼接，不更新梯度做 zero-shot。
  - 数据：同一被试用 8 种脑区划分得到最多 8 个图样本。
- 关键数字：约 40 万图样本、27 个数据集、25 种疾病；消融显示"+语言提示"在所有 regime 最优，zero-shot 下差距最大。
- 【对 MAS 故障归因的可借鉴点】相关度：**中**
  - "同一对象多种图构造 = 数据增强"：同一条轨迹可以建成 agent 图、step 图、超图等多种视图，并配"视图/框架名称 token"（推断）。BrainGFM 的结果显示多图谱联合预训练最好。
  - "框架/任务文本 token"实现零样本：把"MAS 框架描述 + 任务描述（医学场景）"编码成 token 拼入。
  - 局限：领域是脑疾病分类，不是节点定位；无 LLM 生成。

### #12 ALL-IN（ICLR 2026，图基础模型）
- 一句话：用随机特征投影加节点协方差算子消除对原始特征空间的依赖，使 GNN 可以直接迁移到特征语义/维度完全不同的新图。
- 核心机制：每次前向重采样高斯投影，再计算中心化的 n×n 节点协方差；对 A^p 传播后的表示也做协方差。多算子 GNN；理论上证明置换不变和期望下正交变换不变。
- 关键数字：未见数据集 Cora 82.13%、CiteSeer 69.12%、PubMed 78.03%；MUTAG 92.90%（超监督 GIN 89.40%）。稠密 n×n 算子的可扩展性有限（作者自述）。
- 【对 MAS 故障归因的可借鉴点】相关度：**低**。MAS 轨迹节点本就是文本，可直接用 LM 嵌入，特征空间对齐不是瓶颈；仅在需要处理框架特有的数值/类别特征（如票数、步序号）时有参考价值（推断）。

### #13 SCGFM（ICML 2026，图基础模型）
- 一句话：以结构为中心的 GFM。用可学习的"几何基"（度量测度空间）加 Gromov–Wasserstein 对齐得到与拓扑异质性无关的结构坐标，并据此重编码节点特征。
- 核心机制：几何基 B_k 是可训练对称矩阵；用 sliced GW 近似；结构坐标是到各基 GW 距离的 softmax；损失为 L_gw + α·L_rec + β·L_div；下游利用 OT 传输计划把特征投影到基上。节点分类转成图分类（PPR 子图）后用原型网络评估。
- 关键数字：Cora 上移除结构对齐语义项导致 70.54%→29.49%；PROTEINS 上移除反而微升（68.70%→68.86%），作者归因于"语义干扰"。
- 【对 MAS 故障归因的可借鉴点】相关度：**低**
  - 实验的消融提供了有用的负面信号：纯结构坐标不足以支撑内容型任务；而标签由拓扑决定时，弱语义信号反而引入噪声。这提示"该任务偏内容还是偏拓扑"需要用数据确认。
  - 其它部分（GW、几何基）面向图级表示，对节点级归因帮助有限。

### #14 GAUGE（ICML 2026，图基础模型）
- 一句话：从行为不变性/几何平坦性角度研究结构可迁移性，提出神经向量丛架构与 Dirichlet 损失。
- 核心机制：每个节点带一个 r 维纤维，用 QR 分解得到正交基；伪平行传输 P=(Q^i)ᵀQ^j；门控展平只聚合几何相容的邻居；预测式损失用邻居的局部坐标预测自身初始表示；适配阶段只微调输入编码和任务适配两个线性层。
- 关键数字：CSL 图同构准确率 92.56%（GIN 29.67%）；对 16 个基线在 few-shot 与 zero-shot 链路预测上基本全面最优。
- 【对 MAS 故障归因的可借鉴点】相关度：**低**。节点级预测误差 e(v_i) 可作为"这个节点是否偏离邻居预期"的信号（τ-不变性恢复算法），与"找出异常步骤"有形式上的类似，但文档中没有任何文本/LLM/轨迹相关的实验，只能当作灵感（推断）。

### #15 When Do Graph Foundation Models Transfer? A Data-Centric Theory（ICML 2026，图基础模型）
- 一句话：用 graphon 理论给出跨域输出偏移的显式分解（采样误差 + 域内在不匹配），并讨论位置编码的稳定性与数据筛选建议。
- 核心机制：把输出差距分解为 ε₁ + ε_gra + ε₂（两图各自的采样项与重标记不变的 graphon 差异）；Eig-PE 的稳定常数对谱间隙敏感，Proj-PE 只依赖 top-k 子空间间隙；实验在合成 graphon 分类基准上进行。
- 关键数字：OOD 尺寸误差迅速饱和接近零，但 in-domain 尺寸因小图曝光不足而恶化（测试误差 U 形）；PE 维度 k 过大时 OOD 误差退化。作者承认合成实验没有干净地验证 Proj-PE 优势，且理论只适用于稠密图。
- 【对 MAS 故障归因的可借鉴点】相关度：**中（只作警示，不作方法）**
  - 迁移成败是"域级数据问题"：训练/测试域之间的内在不匹配是主导项，对应"不同 MAS 框架拓扑/角色/步数差异"。该理论提示要主动做数据筛选/覆盖，例如保证各种规模都有曝光。
  - 局限：理论只适用于稠密图；MAS 轨迹是小而稀疏的图，因此定理不能直接套用（推断）。

### #16 GFM-BA（AAAI 2026，图基础模型）
- 一句话：针对图基础模型的后门攻击，在预训练阶段植入后门，使其在下游微调后仍然有效且隐蔽。
- 核心机制：无标签触发器关联（FPS 选原型嵌入）；节点自适应触发器生成器；通过扰动高敏感参数、最小化持久性损失，把后门锚定在对微调不敏感的参数上。
- 关键数字：持久性实验中 ASR 几乎不降（如 SAMGPT 上 Photo 98.66%，仅降 1.34%）。
- 【对 MAS 故障归因的可借鉴点】相关度：**低**。与归因任务无关；唯一的旁证是文档中的发现"预训练 GCN 在下游微调后绝大多数参数更新很小"，间接支持"少量参数适配即可"。

### #17 MuseGraph（TPAMI 2026，图基础模型）
- 一句话：完全文本化的图指令微调框架。用"节点能量"在 token 预算内压缩图描述，用 GPT-4 生成 CoT 指令包，对 LLaMA-7B 做 LoRA 指令微调。
- 核心机制：无 GNN、无投影器。图描述由 ego 节点列表、一跳邻居列表和随机游走路径组成，由节点能量 H(vᵢ)=T(vᵢ)×⌈log(D(vᵢ)+1)⌉ 选择；每 1000 条标准指令混入 100 条 CoT 指令；按任务复杂度和数据集复杂度动态分配指令包体积。
- 关键数字：节点分类上相对 GNN 基线最高 +19.67%（Cora 上对 GLNN），相对调优的 LLM 基线（BART-large / T5-large / LLaMA）最高 +38.57%。消融中 3 Task+3 Dataset 逐步加入时性能单调提升。
- 【对 MAS 故障归因的可借鉴点】相关度：**中（主要作为对立路线 / 基线）**
  - 它就是"把图展平成文本喂给 LLM"路线，与 Who&When / AEGIS 这类训 LLM 读轨迹的路线同属一类。新方法必须与之对比，证明显式图结构有额外收益。
  - 可借技术：token 预算约束下的压缩/截断（节点能量）、CoT 指令蒸馏、多任务/多数据集指令包混合以避免灾难性遗忘。

### #18 MolE（Nature Communications 2024，图基础模型）
- 一句话：用 DeBERTa 式解耦注意力直接处理分子图，两步预训练（8.42 亿分子自监督加 ChEMBL 多任务监督），在 TDC ADMET 上取得多项最佳。
- 核心机制：原子环境（radius 0）作 token；图拓扑距离矩阵作相对位置，使模型对输入顺序不变；预训练任务是让被掩码原子预测其 radius 2 环境（输入与标签用不同半径，避免信息泄露）。
- 关键数字：TDC 22 个任务中 10 个最佳（2023 年 9 月榜单）；去掉解耦注意力后掩码建模准确率从 0.96 降到 0.12。
- 【对 MAS 故障归因的可借鉴点】相关度：**低**。可借鉴"相对位置 = 图上最短路距离（可加时间距离）"的注意力设计，以及"输入细粒度、预测目标更粗粒度以避免平凡任务"的预训练设计（推断）；其余是分子领域。

## 本段综合

### (a) 与该 idea 最相关的论文（按重要性）
1. **GOFA (#6)**：冻结 LLM 加交错 GNN 层，零初始化门控，prompt 条件化的消息传递，既保留 LLM 的语义/生成，又获得结构感知。它是"graph+LLM"架构的最直接模板，并且文档给出了对"展平文本"路线的正面对比（准确率高 7%–69%，推理更快，长序列时展平的 LLM OOM）。
2. **UniGraph (#7)**：LM+GNN 级联、掩码文本重建的自监督预训练，以及"图嵌入线性投影到 LLM 词嵌入空间加 LoRA 生成式输出标签"的零样本接口，与"训一个(超)图大模型"的形态最接近。
3. **ZeroG (#8)**：轻量 adapter 的实证（只训 0.07M 的 LoRA；全参数微调严重过拟合），以及"节点文本 vs 类别文本相似度"的零样本打分方式，对应"最多做轻量 adapter 微调"的约束。
4. **OFA (#1)**：TAG 统一加 NOI prompt 节点加类节点的任务模板，是把"归因"统一成图上选择问题的现成模板；prompt 节点还可以做超边的星形展开。
5. **GraphPFN (#10)**：用设计过的合成先验预训练加冻结骨干加图适配器，并给出了先验分布覆盖不足时的失败案例。它与用户"主要靠合成数据训练"的处境最贴近。
6. **GIT (#5) / GFT (#4)**：任务树（虚拟任务节点）统一多节点任务；GFT 冻结词汇的做法可以抑制负迁移；GIT 的"通用预训练加领域特化后训练"流程。

### (b) 可直接搬用的技术组件
- 任务统一：NOI prompt 节点（OFA / GOFA）、类节点加文本描述（OFA / ZeroG）、虚拟任务节点（GFT / GIT）。以 (agent, step) 为 NOI，以"责任类/错误类型描述"为类节点。
- 超边实现方式：用携带文本的超边节点连接所有参与节点（即超图的 bipartite incidence 图），不需要新的超图骨干，可套用上述任一框架（推断）。
- 图 token → LLM：线性投影到词嵌入空间（UniGraph-IT），或 memory token 加交错 GNN 层（GOFA）；门控零初始化（GOFA）。
- Adapter：LoRA（ZeroG，rank=4，仅 W_q、W_v）；冻结骨干只训图适配器（GraphPFN）；冻结词汇、只调编码器和头（GFT）。
- 零样本打分：节点文本嵌入与类别/责任描述嵌入的相似度（ZeroG / GIT-G）。
- 自监督：掩码文本用邻居重建（UniGraph）；neighbor matching（PRODIGY）；掩码边预测（GraphPFN）。
- 合成数据：设计多样性先验，对拓扑/角色/轮数/规则等超参数从分布中采样（GraphPFN）。
- 多视图/多图谱联合预训练加视图或框架名称文本 token（BrainGFM）。
- 压缩：token 预算内选择关键节点（MuseGraph 的节点能量）。
- 结构位置：以最短路距离作为相对位置（MolE 的解耦注意力），RWSE（BrainGFM）。

### (c) 反面证据 / 风险
1. **零样本绝对性能偏低，且依赖标签文本语义**：OFA 的 ogbn-arxiv 5-way 0-shot 为 46.19%、Cora 2-way 为 56.92%；GIT-G 的 held-out 0-shot 平均只有 27.50（GIT-S 特化后 36.32）。ZeroG 跨域比同域下降 8.90%–11.77%（Pubmed / Citeseer）。这些任务都是分类，本段没有一篇测过"定位因果责任"。
2. **同域/单数据集训练胜过跨域**：UniGraph-single 在 Cora 上高于跨域版（84.23% vs 81.43%），加入同域数据后 WN18RR 明显提升；GIT-S 仍弱于领域专家（分子上 GIMLET 64.15 对 62.83）。对应：跨 MAS 框架零样本可能是最难的设定，需要至少少量目标框架数据。
3. **负迁移与任务混淆**：Position 指出直接用链路预测预训练会对节点分类负迁移；OFA 消融显示联合训练时去掉任务/类节点会混淆任务；GFT 把冻结词汇作为抑制手段。
4. **合成先验失配**：GraphPFN 在先验未覆盖的真实图上失败（hm-prices、city-roads-M）；Position 提到数据质量问题（CiteSeer 超过 15% 错标；同一结构不同标签呈相反同配性）。对应"故障注入数据带模板伪迹 + 人工标注极少"。
5. **纯结构不够，语义必须到位**：SCGFM 的消融显示去掉语义项会使 Cora 从 70.54% 降到 29.49%，而标签由拓扑决定的数据集上语义反而干扰。MAS 归因多半依赖内容对错判断（推断），所以必须有强文本编码器。
6. **"LLM 作为预测器"的证据互相冲突**：Position 说简单 flatten 进 prompt 没有提升且与训练好的 GNN 差距大；GOFA 则报告在同等信息下图感知模型胜过展平文本；MuseGraph 说文本化加指令微调就能超过多数基线。MAS 轨迹通常较短（推断：可能不会触发 GOFA 所指的长序列 OOM），所以图结构相对文本的收益不能预设，必须用消融实证。
7. **过拟合 / 全参数微调风险**：ZeroG 去掉 LoRA 后 Cora 降 51.36%、Citeseer 降 40.96%；GraphPFN 随机初始化适配器会显著退化，说明预训练不可省。
8. **迁移的数据中心理论限制**：#15 指出域内在不匹配是主要项，且理论仅适用于稠密图，MAS 轨迹是小稀疏图，理论无法直接支撑。
9. **缩放饱和**：ULTRA 预训练图超过 3 个后零样本性能饱和；GFT 词汇大小不敏感。堆数据不一定带来增益。
10. **任务形式缺口**：本段方法的"零样本"评测全部是类别标签空间上的分类、链路预测或生成。没有一篇处理"一条轨迹内多个候选步骤中找责任步"的排序/因果问题，也没有一篇处理超边。这既是新颖性空间，也是没有直接先例可引用的风险。OFA 不支持回归，GOFA 零样本评估集中在任务格式相似的数据集。

### (d) 可能的直接竞争者 / 必须对比的基线
- **文本展平 LLM 路线**：MuseGraph 式（节点能量压缩、CoT 指令微调、LoRA），以及同族的 Who&When / AEGIS / med-SFT。这是核心对照：证明显式图/超图结构带来增益。
- **GOFA**：图感知 LLM，架构上最接近；需要比较"普通图版 vs 超边版"。
- **UniGraph（含 UniGraph-IT）、OFA、ZeroG**：把 MAS 轨迹建成 TAG 后可直接运行的零样本图基础模型。
- **GIT / GFT**：轻量 GNN 路线，作为"不带 LLM 的图基础模型"基线。
- **PRODIGY 式 in-context**：用少量人工标注轨迹做示例，对应"少标注"设定。
- **消融用的朴素基线**：LM 嵌入特征加普通 GNN（GCN/GAT/GIN）；LM 嵌入加相似度（不使用图）；去掉超边（只用成对边）；仅 LoRA 的纯文本 LLM。
- **GraphPFN**：只作为"合成先验预训练"的方法学对照，不是任务上的直接竞争者（它面向表格节点任务）。
