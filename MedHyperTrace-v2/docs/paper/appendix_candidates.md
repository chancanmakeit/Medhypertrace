# 附录候选(用户第 101 轮:"P-TT 可以记录,后续也可以考虑作为附录拓展")

## A1 · P-TT:用公开归因标签做 LoRA 后训练(线 2 HP2)

- **做法:** Qwen3-8B(后训练版)加 LoRA r16 / α32(all-linear)和步骤打分头,在 TracerTraj 3,208 条训练轨迹上训练 2 个 epoch(`hgfm/posttrain/lora_score.py --train tt`)。
- **公开 WW + TEgc(356 条,jac0.7 聚类 bootstrap):**
  - P-TT 控制后 0.639,F-TT(冻结线性探针)0.571;
  - 差值 **+0.068 [+0.032, +0.104]**,网格 6/6;
  - 原始差 +0.033 [−0.001, +0.064]。
- **零样本迁移到医学分叉集:** −0.007 [−0.059, +0.042],无增益。
- **作为医学后训练的初始化(P-MED/TT):** 比 P-MED 高 +0.084,但只回到冻结探针的水平。
- **可写的结论:** 有足够标签时,同域 LoRA 后训练能在步长 / 位置控制下超过冻结探针;跨域(公开 → 医学)不迁移。
