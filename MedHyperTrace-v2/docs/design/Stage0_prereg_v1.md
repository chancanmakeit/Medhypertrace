## Q1 标签效率(检验动机 1:中训练是否减少下游所需标签)
- **子集:**
  - 从 TracerTraj 训练集(E4 的 `tt_ww/train`,候选步中含标签步的轨迹)按**题目分组**(归一化题干):
  - 5 次抽取(d = 0..4):每次把题目组随机排序,按序累加,直到 ≥ n 条为止;n ∈ {100, 300, 1000},**嵌套**:100 ⊂ 300 ⊂ 1000。全量(约 2,889)= E4 已有结果。
  - 早停用全部验证集(319 条,所有设定相同)。这本身用到了额外的标签,写明。
- **A 阶段(主):**
  - 冻结代理 + 线性头(主)/ MLP 头(次),配方与 E4 相同;每次抽取一个头种子(= d);
  - 指标:每条轨迹先在 5 次抽取上取平均,再合并 WW + TEgc(n = 356)。
- **主统计量:** tapt − base 的**控制后**合并 rank-AUROC 在 n ∈ {100, 300, 1000} 三点上的平均("标签效率面积")。另报告每个 n 的原始值、控制后的值、匹配配对 (r 1.5, w 0.25) 的值。
- **判定:**
  - 面积的 CI 下界 > 0 → **成立**(中训练提高标签效率);
  - CI 上界 < +0.04 → **无效**(停掉"为标签效率做这种中训练");
  - 其他 → 未定。
- 其他代理(S、R、shuf、irr、full)对 base 的同一统计量只描述,不判定;full 用于 Q3。
- **B 阶段(次,只描述):** BEFT,base vs tapt,n ∈ {100, 300},只取第 0 次抽取的子集(再交 ≤16k token 的条件),epoch 数 10 / 6,每个 epoch 验证一次,其余同 E4。单次抽取,不判定。

## Q2 负对照(E1 的"未定"能否分辨)
- **数据:** E1 OAT,对 shuf、irr 重跑(R、S、tapt、base 已有)。
- **主指标:**
  - 匹配配对 rank-AUROC,(r 1.5, w 0.25),即第 75 轮 tapt − base = +0.059 的那一档;另报告全部 6 个容差;
  - 再加控制后的合并 rank-AUROC。
- **比较:** R − base、shuf − base、irr − base;R − shuf;R − irr。
- **判读规则(按顺序取第一个满足的):**
  1. irr − base 的 CI 下界 > 0,且 R − irr 的 CI 含 0 → **通用续训漂移**:E1 的增益与 MAS 内容无关;
  2. R − irr 的 CI 下界 > 0,且 R − shuf 的 CI 下界 > 0 → **轨迹顺序 / 结构起作用**;
  3. R − irr 的 CI 下界 > 0,且 R − shuf 的 CI 含 0 → **起作用的是 MAS 内容,不是顺序**;
  4. 其他 → 未定。
- E4 A 阶段在全量标签下的 shuf / irr 结果只描述。

## Q3 剂量(检验"语料不够"这一说法)
- **比较:** full(34.42M)− tapt(24.46M)。
- **主指标:** 与 Q1 相同的标签效率面积(控制后)。
- **次指标:** E1 匹配配对 (1.5, 0.25);E4 A 阶段线性头,全量标签,3 个种子,控制后。
- **判定:**
  - 主指标 CI 下界 > 0 → **正斜率**;
  - 主指标和 E1 匹配配对的 CI 上界都 < +0.04 → **无效**(不为这种目标扩语料,也不付费生成同类语料);
  - 其他 → 未定。
- **局限(预先写明):**
  - 剂量只有 1.41 倍——这是现有转换语料在我方规则下的上限,不是 issue #3 说的约 75M;那个数是第 53 轮按 字符/4 对原始数据的粗估,第 79 轮更正;
  - 混合比例也变了(ARIA 占比约 41% → 约 60%);
  - full 去掉了评测重复题,tapt 没有。
  - 所以"无效"只能说明"在可得范围内加量没有用",不能外推到 0.1B。
