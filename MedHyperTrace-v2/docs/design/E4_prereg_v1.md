# E4 预注册 v1(第 73 轮,2026-10-28,写于任何 E4 结果产生之前)

**问题:** 中训练(TAPT)能否让**有监督的**归因后训练学得更好?E1–E3 只检验了无标签的读出,增益在控制步长后为零(第 68 轮)。E4 用带标签的数据(TracerTraj)。唯一的变量是初始化:基座 vs TAPT。S / R 两个检查点作为附带对照。

## 数据
- **训练 / 选择:** TracerTraj 公开版(AgenTracer `data-v1.0.0`,审计见 `results/tracertraj_audit/`),用 `data_tools/tracertraj_to_ww.py` 转成 Who&When 格式。
  - agentic 部分的步骤编号减 1;
  - 测试集中题目与训练集重复的样本剔除;
  - 训练集按题目分组,固定随机抽 10% 作验证集,只用于早停和选模型。
- **评测:**
  - 主:WW 182 + TEgc 174,合并 356(与 E1–E3 相同,都没见过 TracerTraj);
  - 次:TracerTraj 测试集,分布内参考。
- **长度规则:** 同 E1,≤32k token 原生,32k–131k 用 YaRN ×4,>131k 跳过并计数。B 阶段训练只用 ≤16k token 的训练轨迹(显存限制),评测用全部轨迹。

## 模型
- **步骤表示:** 冻结 / 微调后的 LM 末层隐状态,在该步 token 上取均值(OAT 的序列化和步骤边界,flash-attn 2)。打分头 = LayerNorm → 线性层(A 阶段另报 MLP 256),对候选步(模型步)做 softmax 交叉熵,标签为错误步。
- **A 阶段(主,便宜):** LM 冻结,只训打分头。代理 LLM:base、tapt、S、R。3 个种子,先算每个种子的指标再按轨迹取平均。早停看验证集 rank-AUROC(耐心 5 轮,最多 30 轮)。
- **B 阶段(微调):** BEFT,即只训注入的 v_proj 偏置 b_v(Qwen3 的 q/k/v 没有偏置,初始化为 0;每层 1,024 维 × 36 层 ≈ 3.7 万参数)+ 打分头,端到端。
  - 选 BEFT 不选 LoRA 的理由:参数少,两种初始化之间的差别不容易被后训练抹平,这正是要检验的东西;训练集约 3.2k 条,属于 BEFT 论文所说的低数据量区间。
  - 注意:BEFT 每步的计算量和 LoRA 相同,反向传播仍要穿过整个网络,只省优化器状态。
  - 设置:DDP、flash-attn 2、Liger(RMSNorm / RoPE / SwiGLU)、梯度检查点;每种初始化 1 个种子(算力限制),2 个 epoch,按验证集选检查点。
- LoRA 只作为可选的 C 阶段,不在本预注册的判定里。

## 指标与判定
- **指标:** 轨迹内 rank-AUROC、Acc@1(= 论文的步骤级准确率)、Hit@3。按第 68 轮的常设规则,每个数字都同时报告原始值和**控制后**的值。控制方法:对 log 步长、相对位置、是否含代码,做带轨迹固定效应的 OLS,不用标签拟合,对残差打分。平凡基线:随机、第一步、最后一步、最长步。区间:按轨迹做配对 bootstrap 1000 次。
- **A 阶段判定(主):** 合并 356 条上,控制后的 rank-AUROC 差 tapt − base 的 95% CI 下界 > 0 → "中训练改善了供有监督归因使用的表示"。只是原始值成立而控制后不成立 → 记为"步长效应"。
- **B 阶段判定:** 规则相同,比较 BEFT(tapt)− BEFT(base)。
- **同时必须报告:**
  - 每个设定相对随机、相对最长步基线的差(原始值和控制后);
  - TracerTraj 测试集上各设定的值;
  - 和论文(AgenTracer)同口径的 WW 步骤级准确率。
- 无论结果如何都会报告。
