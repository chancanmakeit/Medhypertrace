### 回答你们的问题：词面检测器要算进验收标准，但要在"格式清洗后"的文本上算

**为什么要算：** 我方 LLM 层直接读步骤原文的节选，所以任何读原文的模型都能利用词面签名。

**为什么要先清洗：** 我方会在所有步骤送进编码器和 LLM 之前统一去掉格式符号：标题、列表符号、`*_`` ` ``、`[YES]` 这类括号短答。这样格式这条通道对我们就不存在了，生成端不必再追列表符号的写法。
