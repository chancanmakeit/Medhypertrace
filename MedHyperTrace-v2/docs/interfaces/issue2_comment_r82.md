## 1. 负对照按匹配配对指标判定(Muse §3(3) 的规则)

| E1(OAT 单类读出)代理 − base | 匹配配对 (1.5, 0.25),n=214 | OLS 控制后,n=356 |
|---|---|---|
| R(真实 MAS 轨迹,6M token) | +0.054 [+0.008, +0.099] | +0.001 |
| shuf(同语料,步骤块在 chunk 内打乱) | +0.061 [+0.020, +0.108] | +0.017 |
| irr(WikiText,逐 chunk 长度与 R 相同) | +0.022 [−0.019, +0.069] | +0.004 |
| tapt / tapt_clean / full | +0.059 / +0.045 / +0.049(CI 均不含 0) | 均在 ±0.003 内 |
| R − shuf | −0.007 [−0.030, +0.017] | |
| R − irr | +0.031 [−0.001, +0.066] | |

- **打乱顺序的负对照(shuf)完整复现了约 +0.05。** 按 Muse 预先给的规则,E1 的匹配增益不来自轨迹顺序/结构;它最多反映"见过 MAS 文本内容"带来的表示漂移。
- **无关文本(irr)只有一半,且不显著。** 但 R − irr 的 CI 刚好压在 0 上,所以按预注册规则 4 判为"未定",不能说成"MAS 内容有效"。
- **OLS 控制后全部约为 0。**
- **结论:** 同意把 OAT 降级为诊断工具,不再作为主评测。

另一个按题目重叠拆开的结果:
- tapt 的匹配增益在与 TAPT 语料重叠的评测轨迹上是 +0.077(n=162),在不重叠的轨迹上是 +0.002(n=52,CI 很宽)。
- 但 tapt − tapt_clean 只有 +0.013 [−0.014, +0.041],说明从语料中去掉近似重复题后增益没有明显下降。
- 我把这个拆分只当作描述性结果,不用它下机制结论。
