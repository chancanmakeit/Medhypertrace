**发件方:** MedHyperTrace 会话(方法侧,第 78 轮)。用户请我们把对"引入中训练的动机"和"是否请 medical-aegis 生成中训练语料"的看法发到新 issue,供各方讨论。

## 用户写下的动机(原意转述)
1. **域差异:** MAS 轨迹是一种特殊的结构化文本,与通用基础模型预训练用的非结构化文本存在域差异;中训练可以在一定程度上弥合。
2. **成功轨迹的先验:** 失败的原因千差万别,但成功的 MAS 轨迹有规律——不同成功轨迹会有差别,但不会差太远(用户的类比是方差 / 标准差)。用大量成功轨迹做中训练,应能让模型了解"成功轨迹大致长什么样"。
3. **语料问题:** 中训练通常需要 0.1B–1B 甚至更多 token,是否应请 medical-aegis 跑不同的 MAS 框架,凑够真实轨迹,以及后续可能用于对比的错误轨迹?

下面按"已有证据 → 新核查 → 我方看法 → 建议"组织。所有数字都有出处;新核查的脚本和输出已提交到 Medhypertrace 仓库。

## 一、动机 1(域差异):成立,但目前没有证据表明它是归因的瓶颈
- **域差异确实存在,中训练也确实弥合了它。** TAPT(24.5M token)让 LM loss 从 0.97 降到 0.47,留出集 0.477(`results/figures/`)。E2-S / E2-R(各约 6M)同样大幅下降。
- **但弥合之后,归因没有变好。** 原始指标上的提升都是步长效应:
  - MAA 缺陷层 SFT:TAPT 让 SFT 的训练 loss 更低,但 AUROC 不变(`results/midtrain_pilot/`);
  - E1(OAT 读出):"未定"(长度匹配后约 +0.05,位置卡紧后消失);
  - E4(有监督后训练):控制步长后全部为零(`results/e4/`)。
- **没有剂量效应:** 作为 OAT 的代理,R(约 6M token)的提升不小于 TAPT(24.5M)。
- **我方判断:** "域差异"这个命题本身是对的,但它的检验对象应该是**下游需要多少标签**(标签效率),而不是 LM loss。中训练的价值通常体现在少标签时;全量标签下没有差别(E4),并不排除少标签时有差别。所以动机 1 的正确检验是 E4 的标签效率曲线(100 / 500 / 全量,base vs tapt),零 API,可以马上做。
- **医学域另当别论:** 我们的中训练语料几乎全是非医学的(锚点 normal 只占 3.7M);责任层评测(WW / TEgc)也是非医学的。"医学 MAS 轨迹与通用文本的域差异"这件事,目前还**没有被检验过**。这正是 medical-aegis 语料可能有用的地方(见第四节)。

## 二、动机 2(成功轨迹的先验):已有一个直接的弱阴性结果,新核查显示"成功的规律"主要是"结论一致"
### 2.1 已有证据
- **E2**(第 67 轮,预注册):只用成功运行续训的 S,与用全部结局续训的 R 比较,用逐步 NLL 差 ΔNLL = NLL_S − NLL_R 定位错误步,rank-AUROC 0.456,低于随机。
- **E1b**:把 S 作 OAT 代理,并不比 R 好(S − R −0.013 [−0.021, −0.006])。
- **但这个检验偏弱:** R 中只有 36% 是成功运行,S 和 R 在语料上大量重叠,两个模型几乎一样。所以 E2 只能说明"边际的成功先验在 6M 规模下没有显出作用",还不能否定动机 2。

### 2.2 新核查(第 78 轮,零 API):成功轨迹之间真的更像吗?
- **数据:** medical-aegis 锚点 normal 运行(llama-4-maverick,100 道 MedXpertQA 题 × K = 3,4 个框架,共 1,200 条运行)。
- **规则(计算前固定):** 只在同一题内比较,以消除题目难度的影响。距离用 TF-IDF 余弦距离,每个框架单独拟合。
  - 对"2 对 1 错"的题:Δ_C = d(对, 错) 的均值 − d(对, 对);
  - 对"1 对 2 错"的题:Δ_W = d(对, 错) 的均值 − d(错, 错),并按两条错误运行是否选了同一个错误选项拆开。
  - 运行自己的答案取 `verification.regex_extracted`。注意:该导出里的 `answer` 字段是金标准答案,不是系统答案。
- **结果(合并 4 个框架,全轨迹;去掉最后一步后几乎不变):**

| 比较 | 题数 | 平均差 [95% CI] |
|---|---|---|
| Δ_C:两条成功运行比"成功 vs 失败"更近 | 85 | **+0.032 [+0.024, +0.042]** |
| Δ_W,两条错误运行**选了同一个**错误选项 | 49 | **+0.043 [+0.027, +0.062]** |
| Δ_W,两条错误运行选了**不同**的错误选项 | 16 | −0.009 [−0.027, +0.009] |
| 参考:3 条全对的题,组内平均距离 vs 3 条全错的题 | 130 / 120 | 0.289 vs 0.300(跨题比较,受难度混杂) |

  四个框架方向一致(medagents_mc 上两项都约为 0)。
- **读法:**
  1. 成功运行之间确实更像(+0.032),但**选了同一个错误答案的失败运行之间也一样像,甚至更像**(+0.043)。
  2. 只有选了不同错误答案的失败运行之间才不像。
  3. 所以在这批数据里,"成功轨迹的规律"基本等于"结论一致的轨迹彼此相似";"失败各不相同"基本等于"错误选项不止一个"。这是选择题结构本身带来的,不是成功轨迹特有的性质。
  4. 去掉最后一步后结果几乎不变,说明这种相似贯穿整条推理过程,不只是最后一句答案。
- **局限:** TF-IDF 只看词面;单一 backbone;K = 3;只有医学选择题。开放式任务里,"对的结论"不唯一,结果可能不同。

### 2.3 对动机 2 的看法
- **类比需要换一个说法。** 动机 2 实际说的是单类密度估计(one-class / 典型集):用成功轨迹学一个分布,失败处表现为偏离。OAT 就是这个思路(只用成功轨迹训练 CDE),在我们控制步长后约 0.54–0.59。
- **用似然做偏离检测有已知的失败模式:** 高维生成模型给分布外样本的似然可能更高,而且似然主要由表面统计量决定(长度、词频、格式)。我们 E1–E4 里反复撞到的"步长",就是这个问题的具体表现。
- **还有一个更根本的问题:** 失败轨迹里**绝大多数步骤本身是正常的**,决定性的错误步在局部也通常是流畅、像样的。它错在相对于题目的事实或推理,而只看成功轨迹的语言模型,并不知道这道题的正确答案。成功先验是**轨迹级**的,归因却是**步骤级**的。
- **我方结论:** "边际的成功轨迹先验"不太可能单靠堆量起作用,2.2 的数据也提示它学到的主要是"结论一致"。但动机 2 有一个更强的**条件版本**值得保留:**同一道题的成功运行与失败运行做对比**——在哪一步开始分叉、分叉后发生了什么。这需要的不是更多成功轨迹,而是**成对**的轨迹(同题 K 次、有对有错),最好再加上分叉干预(已有的分叉试点:79 个点、12 次翻转)。

## 三、动机 3(语料量):目前的瓶颈不是量
- **数据量没有被用完:** 干净的公开语料约 75M token,TAPT 只用了 24.5M(ARIA 封顶 10M)。
- **没有观察到剂量效应**(见第一节)。把一个零效应的配方扩大 10 倍,预期还是零。
- **在花钱扩语料之前,应先做零 API 的剂量检验:** TAPT 用全部约 75M 干净语料,与 24.5M 版本比较;按 E4 协议评测(标签效率 + 步长控制 + 匹配配对)。约 6 小时 GPU。如果从 24.5M 到 75M 仍然没有任何正斜率,就没有理由去买 0.1B–1B。
- **按此前记录的单价粗算付费生成的成本:**
  - 单价:每千条运行约 $2–3(方法侧第 66 轮的记录,需 medical-aegis 按当前 backbone 复核);
  - 锚点 normal 运行序列化后平均约 4.1k token(3.7M / 900 条);
  - 0.1B token ≈ 2.4 万条运行 ≈ $50–75;1B ≈ 24 万条 ≈ $500–750。
- **还有两个限制,可能比钱更紧:**
  1. **题库:** 可用的医学题,扣掉 MAA 排除清单和所有评测题、并按题目分组去重之后,还剩多少?
  2. **多样性:** 同一道题跑 K 次得到的 token,信息量远低于 K 道不同的题。

## 四、我方建议:请 medical-aegis 生成,但先要"对的数据",后要"多的数据",按门槛分阶段
- **阶段 0(我方,零 API,与本 issue 讨论同时进行):**
  - 标签效率曲线(检验动机 1);
  - 负对照中训练(打乱 / 无关文本,同 token 量);
  - 剂量检验(24.5M → 75M);
  - 按题目分组的 manifest + 基准审计表。
- **阶段 1(medical-aegis,小额付费,约 $5–15,用户批准后):** 医学自然运行,目标约 10–20M token。要求:
  - 按难度筛题:llama 的准确率在 0.25–0.75 之间,保证同题内有对有错;
  - 每题 K ≥ 4;
  - 至少 6 个框架族;
  - 带运行时记录的输入和 sources(超图需要);
  - 按 MAA 排除清单和评测题去重;按题目分组写进 manifest。
  - 这批数据同时检验两件事:医学域差异(动机 1 的医学版);同题成败对比(动机 2 的条件版)。
  - 评测:医学分叉点(责任层)+ MAA(缺陷层)。
- **阶段 2(扩到 0.1B+):** 只在阶段 0 / 1 出现正斜率(控制后、匹配后)时才做。
  - 生成哪一种语料,由阶段 1 的结果决定:是更多成功轨迹、更多成对运行,还是更多分叉对。
  - 停止规则沿用第 75 轮:控制后差值的 CI 上界 < +0.04,就停掉这个配方。
