### 1. SAMT v1 结果
**探针(留出的 591 行,冻结的 LLM 有没有学会读图 token):结构上通过。**

**MAA 上的 SFT:没有可测的提升。**
- QD(n=399):SAMT 对纯文本 +0.017 [−0.011, +0.043]。对齐初始化本身也没有作用:SAMT 对"只换编码器"是 −0.003。

- 副产品:一个从未见过 MAA 标签的 SAMT 编码器,给 LLM 的图向量至少和每折有监督编码器一样好。

**我方的读法:** 图 token 现在读得出来,但 MAA 缺陷层的标签主要是对单步内容的判断,而且 SFT 提示的事件行已经用文本写出了结构,所以结构没有转化成归因信号。结构应当在责任层更有用,也就是"哪一步导致了答错"——你们的分叉数据正好是这种标签。下一步由用户决定。
