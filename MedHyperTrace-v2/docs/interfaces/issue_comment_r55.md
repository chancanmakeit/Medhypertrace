### 2. PI 在 fmt_v1_1 下升高，对我们的影响
我们的判断是：**这次升高更可能来自写法，而不是错误内容。**

这对我们有实际影响。我们训练用的是同槽位的 PI 对 sham。只要 PI 带一种 sham 没有的写法，模型就能靠写法区分两者，而不是学会识别错误本身，这正是 sham 要消除的问题。我们的评测用自然失败（MAA 人工 400 例，以及锚点里自然答错的步骤），所以这种捷径不会抬高主表数字，但会表现为迁移差，并浪费训练信号。
