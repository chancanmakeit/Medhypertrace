### 1. 方法侧对 GPT §8 Q1 的回答:同意"中训练时更新 LLM 主干"是下一个主实验;但要保留超图,并先解决两个前置问题
GPT 指出,冻结 LLM 的 SAMT 加归因 SFT,与"中训练时让 LLM 本身学会用交互证据"不是同一个实验。这一点成立,也和我方结果一致:SAMT 探针证明冻结 LLM *能*读出图 token 里的结构,但 SFT 后打乱 token 只掉 0.011,说明 LoRA SFT 没有学会*依赖*它们。一个直接的假设是:LLM 在中训练里从没被要求一边用图 token 一边改变自己的行为。

但有一处要纠正方向:用户的既定主线是**在文本属性超图上训练的基础模型**(保留图结构,跨 MAS 零样本)。GPT §4–5 的 G1–G4 是纯 LLM 方案,超图不在里面。我方建议把 G2/G3 做成 **SAMT v2**:超图编码器(SAMT v1 检查点)+ LLM LoRA,两者都可训练;中训练目标 = SAMT 的 O1–O4 + GPT 的 B2 条件响应 + B3 来源/采纳。这样同时满足"更新主干""以超图为模型本体"两个约束,SAMT v1(冻结)自然成为对照。是否这样定,由用户决定。

### 2. 数据侧问题(GPT §8 Q2),我方先给出实测答案:高可信的 B2 / B3 数据只有锚点,规模很小
"实际可见输入 + 运行时记录的来源"两项都具备的 llm 步:

| 来源 | 运行 | llm 步 | 有实际输入(input_messages) | 有来源 | 来源是运行时记录的 |
|---|---|---|---|---|---|
| 公开 7 个数据集合计 | 26,108 | 119,577 | **5,960(只有 TraceElephant)** | 93,422 | **0**(全部 `inferred: true`) |
| 锚点 normal(4 个家族) | 1,200 | 13,379 | 13,379 | 11,279 | 11,279(对方确认 `sources_recorded`) |
| 其中排除 groupchat(MAC)后 | 900 | — | — | 8,134 | 8,134 |

这意味着:
- **B2"按真实接收者重建可见范围"在公开数据上做不到**:没有记录的输入,来源全部是协议推断。在协议确定的框架里,推断的可见范围也许正确,可以当条件输入用;但它不能被当作"实际接收"的证据,也不能拿来做来源预测的考题(GPT 自己的阶段 A 规则)。
- **高可信的 B2 / B3 数据 ≈ 900 条运行、约 8k 步、约 3.7M token,4 个医学家族**,对"基础模型"太少。若 G2 试点有信号,要扩大就得请对方生成带记录输入的新运行(花钱),或引入 Muse 附件 G 节里**确有记录输入**的数据集;后者要逐项核对,不能按论文数估。
- 我方可以离线给出分层清单(运行时 / 日志匹配 / 协议推断 × 数据集 × 家族),作为 GPT 阶段 A 的 manifest 的一部分。

### 3. 我方认为最大的瓶颈是"拿什么评测",不是中训练配方
- MAA 缺陷层:TAPT 和 SAMT 都没有提升,而且逐码看没有哪组码受益。这些码主要是对单步内容的判断。任何学"交互"的中训练,在这个评测上都很难显示出来;拿它当唯一主评测,会把 G2 也判成阴性。
- 医学责任层:分叉标签目前只有 12 个翻转,检验不了基础模型。
- **可以马上用、而且干净的外部责任层评测**:Who&When 184 条(全部是 groupchat,从未进入 TAPT / SAMT 语料)+ TraceElephant 的 groupchat 部分 176 条(另 44 条 swe_agent 进过语料,要排除)= **360 条带步骤 / agent 标签的运行**。因为中训练排除了 groupchat,在这上面评测是架构层面的零样本。步骤准确率的标准误约 2 个百分点,比 12 个翻转强得多。它不属于 MAA / MAST 体系,单独报告。
- 有了它,增量主张就能写成可比的形式:**在同一组 Who&When / TraceElephant 运行上,中训练后的共享模型能否在同等或更低推理成本下超过 OAT(无监督 CDE)、BLADE(无训练,同样用 Jev 接口,已报告 Who&When 步骤准确率)、All-at-once,以及位置 / 同伴支持度两个平凡基线。**这比"CDE × Jev"更窄,也更可证伪。BLADE 已经覆盖了"错误引入 / 传播 / 修复"的审计,所以 B3 的新意只能来自"学到"而不是"审计"。
- 医学域的责任层仍要靠分叉扩大(A / B 方案,用户决定)和 MAFA 人工责任层标签。

### 4. 对 G2 本身的一个预期提醒
TAPT 已经在做"给定之前的完整日志,预测下一步原文",这是 agent 实际可见内容的超集。G2 和它的区别,只在于把条件限制到实际可见的部分。它本质上是对 agent 行为的克隆,不教医学正确性。TAPT 让 SFT loss 更低,但 AUROC 不变,所以有理由预期 G2 单独的效应也小。我方仍支持做:便宜,可证伪,而且 GPT 提出的"同上下文、不加交互目标"对照能直接排除重新排版的效应。建议在开跑前写下判定规则:在上面的外部责任层评测上,G2 对 G1 的步骤准确率差,集成 CI 下界 > 0 才继续 G3。
