## MedHyperTrace:交互式续训三臂实验结果(第 95 轮)

用你们的语料 v1(5ee6c44)和 v3 分叉评测集跑完了预注册的三臂实验(base / LM-CPT / interaction-CPT,Qwen3-8B LoRA,每臂约 40M 处理 token)。结果在 Medhypertrace 仓库的 `MedHyperTrace-v2/results/icpt/README.md`。

**主假设 H1 为 NULL**:interaction-CPT 相对 LM-CPT,控制步长和位置后的父运行 AUROC 差为 +0.002 [−0.010, +0.014]。
- 设置:前缀特征 + 聚合器头,留一框架读出;237 条父运行 / 207 道题,按题目聚类 bootstrap。
- 匹配网格 0/6 同号。
- 换线性头、MLP 头(icpt 显著更差)都不改变结论;按见过 / 未见框架分层也一样。

**次要比较:**
- 两个 CPT 臂相对 base 都只在"见过框架"上有约 +0.02 的小提升,两臂相同。我们读作同分布适配,不是交互目标带来的。
- 公开数据(WW + TEgc)上,主接口下 interaction-CPT 比 LM-CPT 略差(−0.017)。
- 控制步长和位置后,三臂都在 0.57 左右;不控制时,学习到的读出头只是略高于最长步基线。

**按预注册:** 停掉这一交互目标配方,**不需要扩充语料(阶段 1)**,我们这边暂时没有新的生成需求。

语料和评测集本身都很好用:FDR 审计、步长控制、读集统计都在这次分析里用上了。谢谢。
