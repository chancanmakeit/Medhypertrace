## E1–E3 结果(第 67 轮,预注册 `docs/design/E1-E3_prereg_v1.md`,提交 33dd4f7)

完整结果:`MedHyperTrace-v2/results/e1e3/README.md`。责任层(标注的决定性错误步),Who&When 式标签;不与 MAST / MAA 数字合并。
留出集:Who&When 182 条 + TraceElephant groupchat 174 条(合并 356)。两者都是 groupchat,TAPT 语料里没有这类架构。
主指标是轨迹内的 Acc@1 / Hit@3 / rank-AUROC,候选 = 模型步。

**判定(按预注册规则):**
- **E1 成立。** 只把 OAT 的代理 LLM 从 Qwen3-8B 换成我们的 TAPT 检查点(OAT 代码与超参不动,在 MCP-Atlas 成功轨迹上训练),合并后:
  - rank-AUROC +0.027 [+0.009, +0.047],Acc@1 +0.038 [+0.009, +0.068];
  - WW 和 TEgc 分开看也各自成立;
  - 5 个种子里,TAPT 的每个种子都高于基座的每个种子(0.609–0.629 vs 0.587–0.605)。
- **E2 不成立。** 似然比 NLL_S − NLL_R 的 rank-AUROC 为 0.456,低于随机;比"第一个模型步"低 0.120 [−0.160, −0.081],比 NLL_base 低 0.147。

**幅度很小,需要直说:**
- TAPT 代理的 OAT 也只有 Acc@1 0.175、rank-AUROC 0.622。
- 在 WW 上,轨迹内它不比"第一个模型步"好(0.573 vs 0.590);它的优势都在 TEgc 上(0.674 vs 0.561)。
- OAT 自己的池化 AUROC:我们 8B 代理复现到 WW 0.773(论文 27B 代理 0.758)。但这个数里很大一部分来自轨迹间的分数尺度和位置效应,所以预注册用了轨迹内指标。

**事后发现(未预注册,不算结论):**
- 对照分数 NLL_base − NLL_tapt 的 rank-AUROC 为 0.683,WW 和 TEgc 上都是。即 TAPT 降低错误步的 NLL 比降低其他步更多,方向与我们的预期相反。
- 位置只能解释一部分:去掉第一个模型步后仍有 0.667 / 0.687,对应的"剩余最早步"是 0.627 / 0.565。
- 步长、内容类型这两个混杂还没查。
- 下一步需要先预注册,再到新的失败数据上检验,例如你们的分叉点,或另划一份留出集。

**和课程化问题的关系:** E1 支持"中训练 → OAT"这条串联:中训练的隐状态让无监督的动力学读出变好了一点。E2 说明"只用成功轨迹的 LM 对比全部结局的 LM"这条更简单的路行不通,至少在每个数据集内按 token 匹配的设定下是这样。
