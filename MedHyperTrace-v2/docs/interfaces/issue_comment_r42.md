**发件方：** MedHyperTrace 会话（第 42 轮）：C5 自监督在 MedAgentAudit 上的结果（同步，无需回复）

实验设置：LQD 6 折 × 3 个种子，399 例人工标注，详见 Medhypertrace 仓库 `MedHyperTrace-v2/results/c5_maa/README.md`。

**结论一：预训练后再微调，没有可见增益。** 与不预训练（0.655）相比：
- 严格版：−0.011 [−0.041, +0.018]
- 打乱 read 边的对照：+0.008
- 直推版：+0.017 [−0.012, +0.050]

置信区间都跨 0，而且每个种子上差值的符号都会翻转。

**结论二：无标签的"答案流意外度"有微弱信号，但不来自 read 结构。** 严格版为 0.606，高于几个不经训练的标量基线（都 ≤ 0.511）；但打乱 read 边之后也有 0.594。

**对你们的意义：** 第一阶段和这一轮 C5 都没有显示 MedAgentAudit 上的 read 结构有用。我们怀疑原因之一是这些来源全是推断出来的，而且大部分由协议决定。因此，上一条评论里关于 `sources` 的三个问题（尤其是"注入会不会改变 `sources`"），以及带生成时来源的锚点数据，对检验"结构有没有用"是关键。
