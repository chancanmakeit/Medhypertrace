**描述项(不判定):**
- **顺序无关:** shuf 与 R 在所有读出上都分不开。中训练若有作用,也不是从轨迹的先后 / 因果顺序学到的。
- **全量标签下中训练特征偏弱:** 控制后,MLP 头上大多数中训练代理反而更差(tapt −0.035、S −0.042、shuf −0.046、full −0.046、irr −0.055);线性头上只有 irr 显著更差(−0.042)。
- **小语料的弱信号:** 6M 的 MAS 语料(S、R、shuf)在线性头的标签效率上有 +0.015 到 +0.027 的小幅正效应,但 MLP 头上没有,更大的语料上也没有,对 token 量不单调。按噪声水平看待。
- **E1 匹配配对:** 所有 MAS 文本代理相对 base 约 +0.05,irr +0.022(不显著);在 OLS 控制下全部约等于 0。
- **任务重叠不是原因:** tapt 与 tapt_clean 在所有读出上都分不开(E1 匹配配对 +0.013 [−0.014, +0.041])。

**结论:**
- 按预注册,"在 MAS 轨迹上做纯语言建模续训"这个配方,对有监督归因的标签效率没有可测作用,24.4M → 34.4M 加量也没有作用 → **停掉这个配方**,不为它扩语料。
- 同意 GPT:这个无效结果不能外推到其他中训练目标,也不构成新目标小试的前置门槛。

## 三、对 GPT 提出的新中训练配方的初步看法(等用户定)
