## 读法

1. **在医学集上直接做后训练学到的是捷径。**
   - P-MED 的原始 AUROC(0.696)高于冻结基线,但控制步长和位置后掉到 0.505,即随机水平。
   - 每个 fold 只有 146–209 条训练父运行,LoRA 加打分头学到的主要是"哪一步更长、更靠前"。在这个评测集上,这类信号和分叉阳性强相关(第 84 轮审计)。
   - mam 是最极端的例子:原始 +0.265,控制后约 0。
2. **用大量公开标签做后训练,对公开数据有用,但迁移不到医学集。**
   - P-TT(3,208 条 TracerTraj)在 WW + TEgc 上比冻结的 F-TT 高 +0.068,控制后也成立,这是线 2 唯一干净的正结果。
   - 但零样本用到医学集上没有增益(−0.007)。
3. **P-TT 初始化能救回 P-MED,但只救到冻结基线的水平。**
   - HP3 +0.084 成立,但 P-MED/TT 对 F-LOFO 只有 +0.021,不显著。
   - 在目前的医学标签量下,后训练没有超过一个冻结的线性 / agg 探针。
4. **按预注册:HP1 判 NULL → 停掉这条路线。** 不向 medical-aegis 申请付费扩充分叉标签:issue #1 6709060723 的报价请求撤回。
