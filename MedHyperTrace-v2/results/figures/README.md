# 训练过程曲线(第 76 轮,2026-10-28)

**说明:**
- 只画已有运行的日志,没有新训练、没有调 API。
- 脚本 `scripts/plot_training_curves.py`;数据 `training_curves_data.json` 从 Linux #2 原样拷贝,保留 5 位小数,传输时 md5 已核对;脚本打印的数字见 `training_curves_numbers.out`。
- 每张图都有 PNG(200 dpi)和 PDF(矢量,可直接放进论文)两个版本。

**总读法:** 下面的每条曲线都说明"优化本身是成功的":loss 下降、验证指标上升、没有发散。但优化成功 ≠ 归因变好。归因是否变好,只能看留出集上、控制步长/位置之后的结果(E1–E4)。

## 图 1 `fig_tr1_text_midtraining`:文本中训练(TAPT pilot v1、E2-S、E2-R)

**配方(三者相同):**
- MS-Swift `swift pt`(续训预训练),Qwen3-8B,LoRA r 64 / α 128,作用于全部 linear 层;
- lr 1e-4,cosine,1 个 epoch,有效 batch 32 个 chunk;
- 每个 chunk ≤ 4,096 token。

**三者只有语料不同:**

| 运行 | 语料 | 规模 | 步数 |
|---|---|---|---|
| TAPT | 公开 7 个数据集 + 锚点 normal 运行 | 24.5M token | 506 步 |
| E2-S | 只用成功运行 | 6.1M token | 147 步 |
| E2-R | 全部结局 | 6.1M token | 154 步 |

**(a) loss:**
- TAPT 从第一个 batch 的 0.97 降到末 10 个记录的均值 0.47;
- 留出 0.5% chunk 上的 loss 为 0.477,与训练 loss 一致,没有过拟合。
- E2-S 从 1.21 降到 0.55,E2-R 从 1.20 降到 0.59。

**(b) token 准确率:**
- TAPT 从 0.80 升到 0.87,E2-S 从 0.73 升到 0.85,E2-R 从 0.75 升到 0.84。
- 大部分下降发生在前约 20% 的步数里,之后进入平台期。这是典型的领域适应曲线:模型很快学会了轨迹的格式和套话,例如 `[s<k>] role | phase`、工具输出的模板,之后只剩缓慢的改进。

**(c) 按 epoch 比例对齐:**
- TAPT 的起点更低。原因是它的序列化方式与 E2 的语料不同,而且公开数据里格式化的文本更多。
- 三条曲线的绝对值**不能互相比较**:语料、留出集都不同。E2-R 的 loss 高于 E2-S,只说明"失败运行的文本更难预测一些",不能当作结论。

**与归因结果的关系(必须一起读):**
- **MAA SFT(第 62 轮):** TAPT 在 MAA 的 SFT 上没有带来可测的增益。
- **E1(OAT 读出):** 原始 +0.027;线性控制步长后 +0.002。长度匹配配对后仍有约 +0.05,但位置卡紧到 ±0.15 时消失。结论为"未定"。
- **E4(有监督迁移):** 控制后为零。
- 所以图 1 只能支持"中训练在语言建模意义上收敛了",不能支持"中训练改善了归因"。

## 图 2 `fig_tr2_samt`:结构感知中训练 SAMT v1

**配方:**
- 冻结 Qwen3-8B;
- HGFM v0.2 编码器(C1–C4,d = 192,从零开始)+ projector,端到端训练,共 19.1M 可训练参数;
- 4 类图问答 O1–O4,loss 只算答案 token;
- 2 个 epoch,750 步(虚线是 epoch 边界),lr 3e-4,cosine。

**(a)–(b):**
- 答案 loss 从 2.41 降到约 0.06(对数坐标),答案 token 准确率从 0.73 升到 0.98。
- 前 150 步就完成了绝大部分学习。第二个 epoch 只有很小的改进,没有出现过拟合的反弹。

**(c) 梯度范数:**
- 开始时为 10–17:编码器和 projector 都是随机初始化,LLM 的嵌入空间还"看不懂"图 token。
- 约 100 步后降到 0.1–1 的量级,并保持稳定。

**验证:** 留出运行上的探针门槛已经通过(真 token vs 打乱 token):
- O2 读集:0.98 vs 0.51;
- O3 读者:0.99 vs 0.22。

也就是说,冻结 LLM 确实学会了从图 token 读出交互结构。这是本项目**唯一有明确正面证据**的中训练组件。

**但是:** SAMT 之后在 MAA 上做 SFT,仍然没有可测的增益(`../samt_v1/README.md`)。"LLM 能读结构"还没有转化为"归因变好"。

## 图 3 `fig_tr3_beft`:E4 第二阶段,BEFT 在 TracerTraj 上训练

**配方:**
- 冻结 Qwen3-8B;
- 36 层,每层 v_proj 上加一个 1,024 维 fp32 bias,另加一个 LayerNorm + Linear 打分头,共约 49k 可训练参数;
- 损失:在候选步骤上做交叉熵;
- 2 个 epoch,4 卡 × 每次累积 16 条轨迹,约 163 步;
- 两种初始化:基座 Qwen3-8B 与 TAPT。

**(a) 训练 loss:**
- 每个记录点只是**单条**轨迹的 loss,所以噪声很大(0–5)。粗线是 EMA。
- 两条曲线都从约 2.7–2.8 降到约 1.0。

**(b) TracerTraj 验证集 rank-AUROC(每半个 epoch 一次):**
- 基座:0.819 → 0.865 → 0.884 → 0.893。
- TAPT:0.825 → 0.867 → 0.892 → 0.907。
- 训练到最后仍在上升,两个 epoch 并没有训满。

**(c) 偏置的范数:** 单调增长,TAPT 初始化的增长更快(5.3 vs 4.5)。

**要点:**
- 在**同分布**的 TracerTraj 验证集上,TAPT 初始化略好(+0.014,只有单种子、单次运行,没有置信区间)。
- 但迁移到留出的 WW / TEgc 后,控制步长的差为 +0.007,不成立(E4 预注册判定)。
- 同分布上的小优势没有迁移到外部集。这正是为什么论文主结果必须以外部集 + 长度控制为准。

## 图 4 `fig_tr4_probe`:E4 第一阶段,冻结特征上的探针头

**配方:**
- 特征:各代理 LLM 末层中、每个步骤 token 上隐状态的均值;
- 头:linear 或 MLP;
- AdamW,lr 1e-3,最多 30 个 epoch,按验证 rank-AUROC 早停(耐心 5),3 个种子。
- 图里只画基座与 TAPT;E2 的 S、R 特征也训练了,数字见 `training_curves_numbers.out`。

**验证集最好值:**

| 头 | 基座 | TAPT | S | R |
|---|---|---|---|---|
| linear | 0.889–0.891 | 0.894–0.900 | 0.895–0.897 | 0.896–0.897 |
| MLP | 0.903–0.910 | 0.909–0.914 | 0.907–0.914 | 0.906–0.909 |

**读法:**
- 同分布验证上,中训练特征稳定地高 0.005–0.01。
- 但迁移到 WW / TEgc 后:
  - linear 头:原始 +0.036,控制步长后 −0.009;
  - MLP 头:控制后 −0.035 [−0.061, −0.010],显著为负。
- 中训练特征里多出来的东西,主要是步长等表层信号。它在同分布上有用,在外部集上反而有害。
- MLP 头 10–20 个 epoch 就早停,linear 头基本跑满 30 个 epoch。

## 论文里怎么用(建议)
- **图 2(SAMT)** 适合放正文或附录,配合探针门槛表:它证明了"图 token → 冻结 LLM"这条接口是可训练、可读的。
