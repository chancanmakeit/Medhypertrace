### #19 TxGNN（Nature Medicine 2024，A 图基础模型 / 生物医学 KG）
- 一句话：在含 17,080 种疾病、7,957 种药物的异构生物医学知识图谱上预训练单个 GNN，零样本为"从未见过药物的疾病"预测适应症/禁忌症，并给出多跳 KG 路径解释。
- 核心机制：
  - 异构 GNN 编码器（关系特定权重 + 同关系邻居平均 + 残差更新）+ DistMult 解码器，同一模型统一预测适应症与禁忌症。
  - 零样本核心为"疾病池化"：用 1 跳邻域签名向量（基因/表型/暴露/疾病）点积得疾病相似度，取 top-k 相似疾病聚合成 h_sim，再按节点度做门控融合 ĥ=c·h_sim+(1−c)·h，c=0.7·exp(−0.7·deg+0.2)（度越小越多借用外部知识）。
  - 先全关系随机预训练，再仅对药物-疾病关系微调；微调前重新初始化 DistMult 以避免负迁移。
  - GraphMask 解释器：对每条边/每个关系/每层学一个门，拉格朗日松弛下"保预测 + 尽量多 mask"，输出边重要性，重要边组成药物→疾病多跳路径。
- 关键数字：严格零样本下适应症 +19.0%、禁忌症 +23.9%（相对次优基线）；9 个疾病领域划分均第一；仅保留重要性>0.5 的边（平均 14.9% 的边）AUPRC 从 0.890 降到 0.886，只用不重要边则降到 0.628。
- 【可借鉴点】相关度 **中高**：
  - 评测协议：作者指出"随机打乱对再留出"允许模型借同一疾病的其他药物走捷径（shortcut learning），改用"整疾病 / 整疾病领域"留出。可直接类比成"按 MAS 框架留出 / 按任务领域留出"，而非随机划分轨迹。
  - 解释器：GraphMask 式边/消息门控，可在轨迹图上输出"哪些边/步骤/节点对判定失败重要"，且有插入/删除/稳定性三项忠实性指标可套用，天然给出 agent/step 级可解释证据。
  - 度自适应借用：对图中信息稀疏的节点（如只发言一次的 agent）借用相似节点信息的门控思路。
  - 局限：KG 是静态异构图，没有时序，且需要大 KG。

### #20 PASCode（Nature Medicine 2026，A 图基础模型 / 单细胞）
- 一句话：把"供体级表型标签"转导到"单细胞级 PAC 分数"，在群体规模 snRNA-seq 上找出与 AD 表型相关的细胞。
- 核心机制：多种差异丰度（DA）方法 + 稳健秩聚合（RRA）生成正/负聚合标签 → 供体数平衡 → GAT 在细胞相似图上预测聚合标签，PAC score = P(pos)−P(neg) → 下游供体×细胞类型分数矩阵 + RF + SHAP 排序。
- 关键数字：预训练模型跨队列预测 AUC 为 PsychAD holdout 0.85、SEA-AD 0.68、ROSMAP 0.72；PAC 水平差异分析在小胶质细胞得 1148 个 DEG，供体水平仅 220 个。
- 【可借鉴点】相关度 **低-中**：它是任务专用模型，不是图基础模型。唯一可借的思路是"粗粒度标签（整条轨迹答错）→ 细粒度单元打分（step/agent）"的弱监督转导：多种打分器集成 + 秩聚合得伪标签，再用图模型平滑。注意跨队列 AUC 从 0.85 掉到 0.68，说明跨队列迁移明显衰减。

### #21 Novae（Nature Methods 2025，A 图基础模型 / 空间转录组）
- 一句话：在约 2900 万细胞、78 张切片上自监督预训练的图基础模型，可对新切片/新基因 panel/新组织零样本识别空间域并内生校正批次。
- 核心机制：
  - Delaunay 邻接图（删除 >100 微米边），以每个细胞的 n_local 跳子图为输入（可堆 16 层 GAT 而避免过平滑）。
  - Panel 不变的细胞嵌入 = 该 panel 基因的 L2 归一化基因嵌入按表达量加权求和；增强包括"伪批次噪声"和随机子采样基因 panel（模拟不同 panel）。
  - SwAV 改编：相距 2–3 条边的子图为正样本对，投影到 K 个原型，Sinkhorn-Knopp 最优传输做均衡分配，swapped cross-entropy；pan-tissue 原型队列允许部分原型跨切片共享、部分切片特异。
  - 零样本：对新数据取嵌入后 KMeans 生成原型即得域；层次聚类原型得多分辨率。
- 关键数字：乳腺 7/10/15 域下 FIDE 与 JSD 均显著最优（zero-shot 即胜出）；600 万细胞域分配+批次校正只需数秒（对比方法需数天）。
- 【可借鉴点】相关度 **中**：
  - "词表不一致也能零样本"的构造：节点特征 = 对本系统可见"词"（panel）的嵌入做加权求和并归一化，再用"随机子采样词表"做增强。可类比不同 MAS 框架的角色/工具/消息类型集合不一致——用训练时随机丢弃/重命名角色类型来模拟框架差异。
  - 子图输入 + 深层 GAT 避免远距离过平滑；"批次=框架"视角下 OT 均衡原型是一种无需外部校正的跨框架对齐。
  - 局限：任务是无监督聚类（空间域），不是带监督的节点打分，需要自己接一个打分头。

### #22 Nicheformer（Nature Methods 2025，A 图基础模型 / 单细胞+空间组学）
- 一句话：在 1.1 亿细胞的 SpatialCorpus-110M 上预训练的 Transformer，学习含空间语境的细胞表示。
- 核心机制：基因按表达排序 tokenization，前拼 `<ASSAY><MODALITY><ORGANISM>` 三个上下文 token；12 层 Transformer（49.3M 参数），BERT 式 MLM（mask 15%）；细胞嵌入为基因 token 均值池化且**排除上下文 token**（modality token 范数最大，若参与池化会把表示拉向模态，使空间→dissociated 标签迁移完全失败）。预训练阶段**并未显式使用坐标或邻居图**（作者承认为局限）。
- 关键数字：仅 1% 空间数据即优于 3 倍 dissociated 数据；密度预测上 scVI/PCA 线性探测 R² 为负，Nicheformer 显著为正。
- 【可借鉴点】相关度 **低-中**：
  - 负结果/警示：预训练数据的模态匹配比数量重要（"数据多样性而非数量是关键"）——对应"合成注入数据 vs 真实人类标注轨迹"的分布差异风险。
  - 工程细节：上下文 token（框架/数据源标识）可注入，但池化读出时要排除，否则表示被它主导。
  - 它没有用图结构，不能作为"图结构有益"的证据。

### #23 CellVQ（Nature Communications 2026，A 图基础模型 / 单细胞）
- 一句话：用向量量化的"单细胞离散化（SCD）"模块得到可读 cell code 的 5.1 亿参数单细胞基础模型，并配轻量可插拔的 CellVQ-Graph 做可解释知识发现。
- 核心机制：encoder–SCD–decoder；SoftCVQ 码本 2^16，温度 1.0 退火至 1e-8；ZINB 损失只在"未采样基因 + 不多于其数量的未表达基因"上算以缓解稀疏；CellVQ-Graph 把细胞（同批 top-15 近邻）、基因节点、染色质峰节点、文本属性 token（BioGPT tokenizer）并入一张图，用 GAT 注意力权重做解释。
- 关键数字：六类预测任务全部 zero-shot；Pancreas 聚类 NMI 0.9424 / ARI 0.9492；属性预测上 scGPT/scFoundation 准确率低于原始基因表达。
- 【可借鉴点】相关度 **低-中**：
  - "冻结基础模型嵌入 + 轻量图模块 + 注意力权重做解释"的组合，可作为"冻结 LLM/文本编码器 → 轻量 GNN 读出 → 注意力归因"的 adapter 范式。
  - 离散码本统一跨批次表示，可类比把异构框架的 agent 行为压成统一的"行为码"；但这是我的推断，原文只用于细胞。
  - 另一警示：大模型表示可能比原始特征更差（属性预测），因此要保留"原始特征基线"。

### #24 BulkFormer（Cell Systems 2026，A 图基础模型 / bulk 转录组）
- 一句话：约 1.5 亿参数、581,503 份 bulk 转录组预训练的 GNN+Performer 混合基础模型。
- 核心机制：基因表征 = ESM2 蛋白嵌入 + 旋转表达嵌入（REE）+ 样本级全局嵌入，三者相加；每个 block = 1 层 GCN（共表达图，top-20 边，|PCC|<0.4 丢弃）+ K 层 Performer；MLM 掩码 15% 表达值，MSE。消融显示共表达图优于 GO 相似图和 PPI 图。下游分三层接入：表达层、基因层、样本层（max pooling）。
- 关键数字：填补 PCC 0.954；单细胞预训练模型在 bulk 上填补 PCC < 0.15；训练成本为单细胞大模型的 1%–10%。
- 【可借鉴点】相关度 **低-中**：
  - "GNN 显式局部关系 + 线性注意力全局依赖"的混合编码器，适合长轨迹（全局注意力）加角色/消息拓扑（局部图）。
  - 先验图的选择有实证消融（数据驱动共表达图 > 知识库图），提示"从轨迹自身统计构图"可能优于"手工固定拓扑"；但原文是基因域，不能直接外推。
  - 与 #22 同样的警示：预训练模态不匹配会大幅退化。

### #25 Cell-GraphCompass（National Science Review 2025，A 图基础模型 / 单细胞）
- 一句话：把每个细胞建模为"基因图"（节点=基因，边=调控/共表达/染色体位置），用 GNN+Transformer 在约 5000 万人类单细胞上预训练。
- 核心机制：节点特征为基因 ID + 表达值（分箱）+ BioBERT 文本描述嵌入；三类边特征（TF–TG、共表达阈值 0.6、染色体位置）；3 层 GNN → 12 层 Transformer；引入连接所有基因的全局节点；掩码 40% 表达值重构；bulk 敲除预测用"单细胞预训练→bulk 预训练→敲除微调"两阶段迁移，并用两步解码器（先判是否变化，再判上调/下调）处理约 4% 的极端类不平衡。
- 关键数字：10% 数据（scCompass-h5M）上公平重训 Geneformer、scGPT 与 CGCompass，后者在三项下游任务上始终胜出；去掉图结构或去掉预训练均显著下降。
- 【可借鉴点】相关度 **中**：
  - 提供"图结构本身有增益"的公平对照证据（相同数据下换架构，去图结构消融）。
  - 节点文本（BioBERT）+ 多类型边特征的"文本属性多关系图"建法，可对应"消息文本嵌入 + 回复/引用/投票等多类型边"。
  - 全局节点（连接所有节点）可对应"整条轨迹/整场讨论的全局节点"，也恰好近似超边的一种退化实现。
  - 两步解码器（先二分类"是否异常"，再细分）对故障归因的极端类不平衡（绝大多数步骤正确）有参考价值。

### #26 抗淋球菌抗生素发现（Science Translational Medicine 2026，A / 分子 GNN）
- 一句话：用 D-MPNN 对 38,650 个化合物的淋球菌表型数据训练，虚拟筛选约 600 万化合物，发现两个结构新颖的先导化合物。
- 核心机制：分子即图，D-MPNN 沿键做消息传递；与 AttentiveFP、ChemBERTa（化学语言模型）、指纹模型对比；用 Murcko scaffold split 评估泛化；主动学习重训练后二轮筛选。
- 关键数字：scaffold split 下 D-MPNN 的 AUPRC 最高，ChemBERTa 与 AttentiveFP 在 scaffold split 下下降更严重；Broad-800K 前瞻验证 set 1 命中率 86%（44/51），set 2/3 为 54%/50%。
- 【可借鉴点】相关度 **低（但有一条方法论警示）**：作者明确说本质是"泛化任务"，要用 scaffold split 逼出泛化差距，并发现图模型比序列化学语言模型更抗 scaffold 迁移衰减——可作为"按框架留出时结构模型比文本序列模型衰减更小"的假设来源（但这里的"LLM"是小型化学 LM，不是通用 LLM，证据不能直接外推）。主动学习"前瞻验证→并回训练集"的闭环也可用于少量人工标注的利用。

### #27 YuelDesign（Science Advances 2026，A / 分子扩散）
- 一句话：扩散模型在柔性蛋白口袋中联合生成配体与口袋构象。
- 核心机制：口袋只用 Cα 原子（不编码侧链），使用**完全连接图**以便去噪中边权重动态重加权；EGNN 主干；YuelBond 重构键级。
- 关键数字：整体有效性 53.7%；YuelBond* 有效性 65% 对 RDKit 13%。
- 【可借鉴点】相关度 **低**：领域模型，3D 生成。仅一点：当节点数少时可用全连接图并让模型学边权，避免距离/拓扑截断带来的结构僵化——对小规模 MAS 讨论图（agent 数少）可考虑。

### #28 SeFMol（Science Advances 2026，A / 分子扩散 + RL）
- 一句话：把扩散去噪过程当作 MDP，用 PPO 式 RL（带 KL 约束）微调半柔性分子生成。
- 核心机制：动作=单步去噪；奖励仅在最终步给出（稀疏）；用 8 种分子性质作条件缓解中间状态无奖励的稀疏信号；预训练模型作 reference 做 KL 约束防遗忘。
- 关键数字：平均 Vina −7.23 kcal/mol；采样步数 1000→50（20 倍加速）。
- 【可借鉴点】相关度 **低**：与"稀疏终局奖励 + 条件信号引导中间态"的信用分配问题形似（MAS 轨迹只有最终对/错），但原文是生成任务，无直接可用机制。

### #29 CureGraph（Artificial Intelligence 2025，A / 城市多模态图）
- 一句话：对小区的文本、照片、POI 评论三种模态建对比式多模态图，预测老年慢性病患病率。
- 核心机制：每个生活圈对应 3 个模态节点；圈内边（不同模态全连接，角相似度加权）+ 跨圈边（同模态节点，按空间自相关取 top-k=20）；三个对比学习模态编码器（triplet、InfoNCE、SupCon）；SMGCN（GCNII 式残差深层 GCN），训练目标 = 重构空间自相关矩阵 + 拉近文本模态与视觉/POI 模态的距离（跨模态对齐）。
- 关键数字：平均相对最优基线 R² 提升 28%；注意：四种疾病患病率是**仿真数据**（论文自述）。
- 【可借鉴点】相关度 **低-中**：
  - "同一实体的多视角节点圈内全连接 + 跨实体同类节点按相似度连边"的构图法，可类比"同一步骤的 文本/角色/工具调用 多视角"。
  - 以结构重构（空间相关矩阵）为训练目标的结构保持损失。
  - 负结果/警示：标签是仿真的，外推要谨慎；简单拼接式多模态融合反而不如单模态（LINE/Node2Vec）——与"合成标签的伪迹"问题同类。

### #30 OpenGraph（EMNLP Findings 2024，A 图基础模型）
- 一句话：首个明确面向"开放图场景"（训练/测试图的节点、边、特征空间完全不相交）的图基础模型，仅在 LLM 合成图上预训练，零样本到真实图。
- 核心机制：
  - 统一 tokenizer：平滑高阶邻接 Ã=Ā¹+…+Āᴸ（默认 L=3），对每行做快速 SVD 的拓扑感知投影 e_v=Ã_{v,:}·LN(U√Λ‖V√Λ)（d=1024），使任意节点数/特征维度的图得到统一 token；每 10 步重采样投影以增强对投影的适应。
  - 可扩展图 Transformer：batch 内中心/正/负节点序列采样（长度 |V|→3B）+ 锚节点两阶段自注意力，复杂度 O(B×S)。
  - LLM 生成合成图：Tree-of-Prompt 生成节点、文本 Gibbs 采样生成边（含动态概率归一化、局部性衰减、GCN 拓扑模式注入）。
  - 预训练为掩码边预测（MAE）；**节点分类统一为"普通节点 ↔ 类节点"的链接预测**，零样本迁移。
- 关键数字：8 个真实数据集上零样本全部超过 1-shot/5-shot 基线（如 Cora 准确率 0.7504 vs 5-shot 最好基线 0.585 GAT / 0.561 GraphCL）；用真实 Yelp/Gowalla 预训练反而无迁移优势（作者原话 "real-world data can be misleading"）。
- 【可借鉴点】相关度 **高**：
  - 任务统一模板：把"哪个 agent / 哪一步是故障源"重写为"轨迹图中 (候选节点 ↔ 故障类节点) 的链接预测"，零样本无需新增分类头。
  - 统一 tokenizer：纯结构、与特征维度和节点数无关的节点 token，适合步数/拓扑差异巨大的不同 MAS 框架。
  - 合成预训练数据的正反证据：一方面合成数据（含拓扑模式注入）优于真实数据，支持用合成轨迹预训练；另一方面作者消融显示去掉归一化/局部性/拓扑注入任一模块都显著下降，说明合成数据需要精心控制分布，不能直接套故障注入模板。
  - 局限：作者自述尚不支持异构关系/节点类型、可解释性未探索，且全文只在 8 个数据集上验证。

### #31 MDGFM（ICML 2025，A 图基础模型）
- 一句话：多域图基础模型，用图结构学习（GSL）去噪并对齐跨域拓扑，再用 prompt 迁移到目标域。
- 核心机制：
  - 域 token（Hadamard 乘，刻画域特性）+ 共享 token（域无关语义锚点）：X'_i=t_S⊙σ(t_{D_i}⊙X_i)。
  - 可学习 balance token 自适应加权特征与 r 阶聚合拓扑信息，H_i=t_{B_i}⊙[X'_i, A_i^r X'_i]，据此 kNN 精炼邻接矩阵；对原图视图与精炼视图做互信息最大化的对比预训练。
  - 下游：meta prompt（以可训练系数 α_i 混合各源域 token）+ 特异 prompt，编码器冻结，仅训 α_i、p_s、β。
  - 给出理论界（凸包近似目标域分布、不变图学习器）。
- 关键数字：1-shot 跨域迁移全面最优（比次优方法最多高 18.04%），few-shot 最多高 8.11%；四类攻击（加边/删边/随机扰动/Metattack）下稳定最优。
- 【可借鉴点】相关度 **中**：
  - adapter 设计：冻结主干，只训"源域 token 混合系数 + 少量特异 prompt + 防负迁移权重 β"，这是一个符合"最多轻量 adapter"要求的现成配方。
  - 图结构学习去噪：可用于合成轨迹里模板带来的虚假边/虚假依赖的过滤。
  - 警示：作者观察到去掉部分源域后性能偶有提升（域间冲突），说明多框架联合预训练可能互相干扰；其实验是少样本节点分类，且有标注样本时需要适配。

### #32 SAMGPT（WWW 2025 [出处为作者自述级核验]，A 图基础模型）
- 一句话：文本无关的多域预训练 + 跨域适配的结构对齐框架。
- 核心机制：为每个源域的图编码器每层配一个可学习"结构 token"，以元素乘调制邻居聚合 h^l_v=Aggr(h^{l-1}_v,{t^l_Si⊙h^{l-1}_u})；下游冻结编码器，用"整体提示（对齐统一结构知识）+ 特定提示（各源域结构 token 的可学习加权混合 Λ）"调制聚合；原型对比损失，仅优化 P_hol、Λ 与特征适配参数。
- 关键数字：7 个目标域（轮流留出）one-shot 节点分类 6 个最优（如 Cora 47.80% vs GCOPE 35.62%）；去掉结构 token（等价 MDGPT）为最大退化来源；GraphPrompt/GCOPE 随源域增多反而变差，SAMGPT 单调提升。
- 【可借鉴点】相关度 **中高**：
  - 与"不同框架的拓扑统计量（度、最短路径、聚类系数）差异巨大"直接对应——为每个已知 MAS 框架学一个结构 token，新框架上学源 token 的混合系数，参数量极小。
  - 数据消融表明"简单合并多域图会互相干扰"，支持把框架差异显式建模而不是混着训。
  - 局限：m→10 时部分域与 GCOPE 持平，即监督增强会削弱预训练优势；结构 token 是**按源域**的，未见框架只能靠混合已知框架，若新框架与所有源框架都差异大，该机制能否奏效原文没有验证。

### #33 RiemannGFM（WWW 2025 Oral [出处为作者自述级核验]，A 图基础模型）
- 一句话：不用文本，以"树 + 环"为结构词表，在积丛（双曲 × 超球）的黎曼流形上预训练图基础模型。
- 核心机制：product bundle（双曲丛负责树，超球丛负责环），流形保持的黎曼线性操作，跨几何注意力（key/value 来自本几何、query 来自另一几何，单向聚合子孙→自身），bundle convolution（平行传输后消息传递），以双曲/超球视图互为对比视图做几何对比学习，无需图增强。
- 关键数字：链接预测在 4 个数据集上全面最优（如 Citeseer AUC 99.40、Pubmed 94.12）；少样本中 OpenGraph、LLaGA 在 GitHub/Airport（混合/无属性图）上出现**负迁移**。
- 【可借鉴点】相关度 **低-中**：
  - 结构词表思想（树 + 环）：对应 MAS 中的"链式传递（树/链）"与"反馈/辩论回环（环）"，提示可显式提取这两类子结构作为跨框架共享基元；但引入黎曼几何对本任务成本高、收益未知。
  - 负迁移警示：依赖文本属性的共享知识迁不到无文本/混合属性图；对 MAS 的启示是——若不同框架的文本风格差异大，纯文本依赖的 GFM 会出现类似问题，应保留结构通道。注意：MAS 轨迹本身文本丰富，这一警示针对"文本分布变化"，不是"无文本"。
  - 预训练数据影响小这一结论与 OpenGraph 的敏感性形成对照（OpenGraph 在 Citeseer 上用 WikiCS 预训练得 89.64%，用 Flickr 仅 65.16%）。

### #34 GraphGPT / GET（ICML 2025，A 图基础模型）
- 一句话：用（半）欧拉路径把图无损可逆地序列化为 token 序列，用标准 Transformer 做 NTP/SMTP 生成式预训练，并把图/边/节点级任务统一为序列格式。
- 核心机制：
  - 欧拉路径序列化，非欧拉图 Eulerization，不连通图用 `[EDGE_JUMP]`；从候选路径中随机采样一条作数据增强；节点按首次出现顺序重索引，再做循环重索引（i'=(i+r)%N）。
  - 属性挂载（离散属性 token 化、连续属性逐位 token 化、边方向 token）；大图用 ShaDowKHop 采子图；节点身份用 k-token 编码压缩词表。
  - 任务统一：图级追加 `[GSUM]`，边级追加源/目的节点 token，节点级追加目标节点 token，最后一个 token 接 MLP。
  - 默认用 SMTP 预训练（一个节点的所有出现同时 mask）。
- 关键数字：PCQM4Mv2 test MAE 0.0804（B48，453.4M），优于此前 SOTA 0.0821；ogbl-ppa HR@100 76.55（2B 参数）；Triangles 上经带属性图预训练再微调到无属性任务可达 64.3%/86.1%/86.6%（对比基线 32.6%）。
- 【可借鉴点】相关度 **中高**（且是最强的"文本序列路线"对照）：
  - 任务统一模板（尾部追加目标节点/边 token 后读最后一个 token）可直接用于"给定候选 agent/step 做打分"。
  - 重索引作为数据增强，可迁移为"随机重命名 agent / 重排节点编号"，防止模型记忆模板里的固定角色名/编号——这对合成数据的模板伪迹特别有针对性。
  - 随机路径采样的不变性正则、结构 token 与语义 token 分词表的拆分（前者跨数据集可迁移，后者数据集相关）。
  - 警示：作者自述跨领域迁移有限（分子 vs 社交网络），小数据集上不及传统 GNN；训练脚本大图预训练算力昂贵。
  - 需要提醒：该路线本质上把图序列化后交给 Transformer，更接近"LLM 读序列"路线，不能直接作为区别于现有路线的创新点。

### #35 Graph World Model / GWM（ICML 2025，A 图基础模型）
- 一句话：用图表示世界状态，把各种任务表示为连到状态图上的"动作节点"，一个统一的 LLM/消息传递模型处理 6 类任务（含医疗多智能体）。
- 核心机制：
  - 节点携带 image/table/text 多模态信息，边含显式边和嵌入相似度构建的隐式边；动作节点通过直接引用（节点/边/图级的"预期动作"）或嵌入相似度 top-k（"非预期动作"，如 RAG 查询）连到状态图。
  - GWM-T：多模态全转文本，token 级提示式消息传递（h_v^(l)=f_v(Concat(h_v^(l-1),{h_u^(l-1)}))），LLM 指令微调。
  - GWM-E：模态编码器（BERT/CLIP）→ 无参数多跳聚合 X_e^(l)=Ãˡ X_e → MLP 投影器 f_c 得到 X_G=[X_c,X_c^(1),…,X_c^(L)]，冻结 LLM，仅训投影器（类似 prefix tuning）；可扩展到异构图。
  - 6 任务实例化中，多智能体协作用 AgentClinic（医疗），为图级动作。
- 关键数字：GWM-E 在 7 项任务中 5 项优于 GWM-T，token 成本低约 5–10 倍；2k 上下文的 GWM-E 在 LongBench v2 上 33.32，超过 128k 上下文的 GPT-4o mini 的 29.01；仅在非 Agent/RAG 任务上训练的 GWM 在 Agent/RAG 上 zero-shot 甚至超过只用单任务数据训练。
- 【可借鉴点】相关度 **高**（本段最贴近"graph + LLM"路线）：
  - 图 token 投影：GWM-E 的"无参数多跳聚合 + 小 MLP 投影器接冻结 LLM"，正好是"最多轻量 adapter"的实现，且 token 成本远低于把整条轨迹文本塞进 LLM。
  - 任务统一：动作节点（图级/节点级/边级）作为统一查询接口，可自然写成"故障归因动作节点连向所有 agent 节点/步骤节点"。
  - 同一论文含医疗多智能体（AgentClinic）实例，可核实其图构造方式；但解读文档对该任务的具体构图方式、指标写得很少，**需要回读原论文**才知它是否做过 agent/step 级归因（解读里只说"图级动作"，且没有该任务的具体数字）。
  - 警示：多跳过多会过平滑、性能下降；实现聚焦同配图，计划支持异配图；只支持 text/table/image 三种模态。

### #36 SCR（NeurIPS 2025，A 图基础模型）
- 一句话：仅在知识图谱（WN18RR、FB15k237、CodexM）上训练的归纳推理模型，把节点/图分类改写为 KG 补全，零样本迁移到引文、分子、社交等通用图。
- 核心机制：
  - 任务特定 KG 结构：引入"label □"实体和"super graph △"实体，及三种新关系（node is attributed with label / node belongs to super graph / super graph is attributed with label）；分类 = 回答查询 (query entity, is_attributed_with, ?)，天然支持推理时出现未见标签。
  - 语义条件消息传递（SCMP）：随机截断 SVD + LayerNorm 对齐跨域特征（无需训练）；INIT² 用查询节点 top-k 语义邻居（排除拓扑邻居）共享可训练向量初始化，满足可区分性；非参数语义表示用冻结 CMP 预计算后与查询条件表示融合。
  - 训练时轮换 BERT、MPNet、MiniLM、DistilBERT、本体特征、全 1 特征以适应异构特征空间；关系图沿用 ULTRA 的四种关系交互。
- 关键数字：节点分类零微调平均排名 3.67，超过 OpenGraph/AnyGraph/ULTRA(3g)；图分类 8 个数据集平均排名 1.75；KG 归纳推理平均 MRR 0.451（ULTRA(3g) 为 0.433）；换用 MPNet/MiniLM/DistilBERT/全 1 特征时性能几乎持平。
- 【可借鉴点】相关度 **高**：
  - 零样本打分方式：查询条件化的关系/节点打分（query-conditioned message passing），"相对结构表示"不依赖固定标签集或固定特征空间，适合不同框架中角色/标签名不一致的情形。
  - 任务重写模板：分类→KG 补全；可写为 (整条轨迹/某 agent, is_failure_source, ?) 或"step 节点 is_decisive_error"，label 实体 + super graph 实体对应"错误类别 + 整条轨迹"。
  - 特征空间轮换训练：说明对文本编码器选择有鲁棒性，可用于抵御 LLM 编码器版本差异。
  - 局限/警示：训练图是常识 KG 而非交互轨迹；异配图上仅次于解析解调参的 GraphAny；语义信息主要靠相似度近邻，并未显式建模长文本推理。

## 本段综合

### (a) 与该 idea 最相关的 3–6 篇及理由
1. **#35 Graph World Model**：唯一在实验中包含医疗多智能体（AgentClinic）的图基础模型；"动作节点"统一各类任务；GWM-E 的"无参数多跳聚合 + 投影器 + 冻结 LLM"是现成的 graph-LLM 轻量 adapter；报告了对未见任务（Agent/RAG）的 zero-shot 结果。
2. **#36 SCR**：把分类改写成查询条件化的 KG 补全，零样本、对标签集与文本编码器鲁棒，是"零样本节点/step 打分"最直接的模板。
3. **#30 OpenGraph**：统一 tokenizer + 节点分类转链接预测 + 合成数据预训练，直接对应"跨框架零样本 + 合成训练数据"这两个约束，且自带"真实数据可能误导"的合成数据证据。
4. **#34 GraphGPT**：任务统一模板与"随机重索引/随机路径"增强对付模板伪迹和节点编号记忆；同时是最近的"序列化后喂 Transformer"对照路线。
5. **#32 SAMGPT**（辅以 #31 MDGFM）：按框架学结构 token + 下游混合系数的轻量 adapter，正面回应"不同 MAS 框架拓扑差异大"。
6. **#19 TxGNN**：零样本划分协议（整疾病/整领域留出）与 GraphMask 路径解释器及忠实性指标，对应"可解释归因 + 评测设计"。

### (b) 可直接搬用的技术组件清单
- 任务统一：节点分类/归因→"节点 ↔ 类节点/标签实体"链接预测（#30、#36）；图级 `[GSUM]`、边级/节点级尾部目标 token（#34）；动作节点作为统一查询（#35）。
- 图 token / 投影：Ã=Ā¹+…+Āᴸ + 快速 SVD 的拓扑 token（#30，L=3，d=1024）；无参数多跳聚合 Ãˡ X + MLP 投影器接冻结 LLM（#35）；随机截断 SVD+LayerNorm 对齐特征维度（#36）。
- 零样本打分：查询条件化消息传递，非参数语义表示预计算（#36）；INIT² 语义近邻初始化（#36）。
- adapter：域/共享/balance token（#31）；每框架结构 token + 整体/特定双提示 + 混合系数 Λ（#32）；仅训投影器（#35）。
- 数据增强：随机子采样词表/panel 与伪批次噪声（#21）；节点循环重索引与随机欧拉路径（#34）；训练时轮换文本编码器（#36）；LLM 驱动合成图 + 局部性/动态归一化/拓扑模式注入（#30）。
- 可解释：GraphMask 边/消息门控 + 插入/删除/稳定性指标（#19）；GAT 注意力权重热图（#23）。
- 评测：整领域/整框架留出以防捷径学习（#19、#26 的 scaffold split 同理）。
- 不平衡：两步解码（先判是否异常，再判类型）（#25）；全局节点（#25）。
- 弱监督：粗标签→细粒度单元分数的转导（#20，仅作思路）。

### (c) 对该 idea 的反面证据 / 风险
- **空缺证据**：本段没有任何论文在 agent 轨迹的 agent/step 级归因上验证过图基础模型；#35 的医疗多智能体任务是"图级动作"，解读未给出具体归因指标；超图与时序交互图在本段完全没有出现。所谓"明显区别于训 LLM 读轨迹"的新颖性，需要靠自己的实验建立。
- **跨领域/跨框架迁移受限**：#34 作者自述跨领域迁移有限，小数据集上不及传统 GNN；#32 在标注样本增多时优势被削弱，且未验证与所有源域都差异大的新目标域；#19 的零样本也依赖相似疾病的借用（相似节点存在的前提）。
- **域间冲突**：#31 观察到去掉部分源域反而提升，多框架联合预训练可能互相干扰；#32 的数据消融同样显示简单合并多域会变差。
- **合成/不匹配数据**：#30 说真实数据预训练可能误导、合成数据需精心设计分布；#22/#24 表明预训练模态不匹配会严重退化（如单细胞模型在 bulk 上填补 PCC < 0.15）；#29 的标签为仿真数据，其结论外推受限；故障注入的模板伪迹如不被增强/重索引打散，可能被图模型学成捷径。
- **图结构不一定有用或需要新的验证**：#22 Nicheformer 完全没有用图结构也能取得好结果；#23 指出大模型表示可能比原始特征更差；#36 在异配图上弱于 GraphAny；#35 多跳过多过平滑。
- **结构路线的有限性**：#33 的负迁移结论针对无文本/混合属性图，对文本丰富的 MAS 轨迹并不直接适用；纯结构方法无法读懂"这句话是否医学上错误"，故障归因的关键往往在语义内容，需要 LLM 通道。
- **序列化路线可能抹杀区别**：#34 的"图→序列→Transformer"与"LLM 读轨迹文本"同属序列建模，若用此路线，新颖性主要在统一任务模板和增强，而非建模范式。

### (d) 可能成为直接竞争者 / 必须对比的基线
- **图-LLM 统一路线**：#35 GWM（GWM-T 与 GWM-E 两个版本；且其 AgentClinic 实验可作为参考设置）。
- **零样本图基础模型**：#36 SCR、#30 OpenGraph（#36 已将其作为基线），#31 MDGFM、#32 SAMGPT、#33 RiemannGFM（后三者原文做的是少样本/文本无关设置，用于 MAS 需自行适配，只能作为"弱/结构-only 基线"）。
- **序列化路线对照**：#34 GraphGPT/GET（把轨迹图序列化后喂 Transformer）。
- **评测协议借鉴而非基线**：#19 TxGNN 的整领域留出与 GraphMask 解释器。
- **非图基线（用户已有）**：LLM 直接读轨迹（Who&When、AEGIS、med-SFT）；建议再加一个"同数据量下去掉图结构（只保留文本）"的消融，对应 #25 的做法。
